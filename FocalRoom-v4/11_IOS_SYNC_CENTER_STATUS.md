# FocalRoom iPhone 同步中心与云端预览离线缓存开发记录

日期：2026-10-28，Asia/Shanghai。接续 `10_IOS_RESEARCH_VOICE_STATUS.md`；目标「按计划依次进行」，本片为 README 后续顺序第 2 项收尾：离线中心（同步中心 + 云端预览离线缓存）与媒体支持矩阵的自动化部分。服务端零改动、零新增迁移、零新增依赖。

## 已实现

### 同步中心

- `ScopedStore.overview()`：合并“有缓存快照”与“仅剩待提交意图”两类项目，输出标题、版本、最近缓存时间与待提交状态（快照缓存仍随项目清单清理，待提交不随快照淘汰）。
- 项目页右上角入口 → 同步中心：在线/离线状态说明、逐项目行（标题、缓存时间与版本、待提交/待确认/未成功徽标）、跨项目“核对并重试”（先查权威回执、沿用原编号）与“放弃未生效选片”。
- `AppModel.retryPending(projectID:)` / `discardRejected(projectID:)` 参数化：待提交处理不再依赖“当前打开的项目”，选中项目的横幅路径复用同一实现，世代护栏与回执查询语义不变。

### 云端预览离线缓存

- `PreviewCache` actor：按内容摘要寻址的按账户磁盘缓存，上限 150 份 / 128 MiB，最近使用淘汰；命中更新访问时间；文件缺失或长度不符按未命中处理并同步清理索引与文件；`clear()` 整体清除。
- `AppModel.image()` 三级读取：会话内存 → 磁盘缓存 → 网络（下载后经既有 SHA/尺寸核验再落盘）。离线时已查看过的预览可继续浏览，未查看的仍需联网——不伪造离线可用。
- 退出登录与登录失效路径同时清理资料缓存与预览缓存；缓存仅为已授权派生预览的副本，不提升权限、不参与任何授权判断。

### 媒体支持矩阵（自动化部分）

- JPEG/PNG/TIFF/HEIC（编码器可用时）× EXIF 方向 1–8 全组合：逐张导入并断言记录方向与原始尺寸、预览最长边 ≤2048 且方向归正为 1、原片字节摘要一致、去重后全量保留。
- 超 5000 万像素的纯色大图（小字节体积）被明确拒绝，确认像素上限独立于字节上限生效。

## 调试记录

- 淘汰测试初版在越限后才“触碰”旧条目，被淘汰后断言失败——改为先填至限内、触碰、再施加越限压力，验证 LRU 语义本身。
- overview 测试初版先存快照后写项目清单，被 `saveProjects` 的清单过滤清理（既有语义）——调整次序并在测试中注明该约束。
- 冷启动模拟器首轮在系统文件 App 首次索引上超时（预存在的文件导入步骤，25 秒上限），复跑通过；波动与 09/10 记录一致。

## 边界

- 离线可浏览的范围 = 已缓存的项目资料 + 已查看过的预览；未查看预览、研究资料、画布与评论仍需联网。待提交选片离线可记录、联网后经同步中心或项目内核对。
- 媒体矩阵为宿主/macOS 模拟环境下的自动化覆盖；真机上的 HEIC 硬件编码、大图内存与性能、真实语音识别与导出落盘仍列真机验收清单。
- 缓存上限为客户端策略，不构成服务端配额承诺。
