# FocalRoom iPhone 本机资料离线访问与导出开发记录

日期：2026-10-28，Asia/Shanghai。接续 `08_IOS_DEVICES_RECEIPT_STATUS.md`；目标「按计划依次进行」，本片为 README 后续顺序第 2 项中的独立离线访问/导出，直接回应 06 记录提出的边界：“账号不可用或卸载应用时的资料取回能力仍需完善，不应将本机项目作为唯一副本”。

本轮全部改动限于 iPhone 工程与验证脚本，服务端零改动、零新增迁移、零新增依赖。

## 已实现

### FocalRoomCore

- `LocalExportManifest`：版本化导出清单，逐张记录照片标识、原始文件名、导出文件名、源与预览 SHA256、字节数、尺寸、格式、选片状态与迁云状态（阶段和云端项目绑定），脱离本应用即可核对。
- `LocalLibrary.stageExport`：先逐份校验原片摘要再逐字节复制到暂存目录；同名文件自动去重（`frame.jpg`/`frame-2.jpg`）；任何一步失败立即清理整个暂存目录，不留半成品；全程可取消。
- `AccountScope.init(server:userID:)`：按登记过的服务身份字符串离线重建同一资料目录 key，与登录时生成的 key 逐位一致（测试断言）。

### iPhone 应用层

- 离线资料索引 `LocalScopeIndex`：登录时登记账户邮箱与服务地址到应用容器内明文索引（受设备加密保护，不含任何会话凭据）；损坏索引只影响离线列表，不触碰资料本体。
- `LocalLibraryModel` 只读模式：导入、选片、新建项目在只读态硬禁用并给出明确提示；浏览、比较、导出不受影响。
- 导出协调：暂存就绪后经系统文件夹选择器（`UIDocumentPickerViewController`）由用户选择目标；选中后先清空暂存状态再在安全作用域内复制到去重子目录（`FocalRoom-项目名-时间戳`），复制在后台线程执行；取消或失败均清理暂存。
- 登录页“查看本机资料（离线只读）”入口（检测到已登记资料时显示）→ 账户资料列表 → 只读本机项目视图；照片查看器显示“离线只读”标识；导入/迁云入口隐藏。

## 数据边界

- 索引明文内容仅为账户邮箱与服务地址；会话凭据仍只在钥匙串。卸载应用即删除索引与全部本机资料。
- 导出仅含原片与 manifest.json；浏览预览可再生，不随导出。导出前摘要不匹配即中止，不导出损坏字节。
- 离线只读不产生任何写操作；迁云、导入、选片均不可用，界面如实标识，不冒充可编辑状态。

## 调试与边界记录

- iOS 26 系统文件夹选择器部分渲染在独立进程：应用侧取消按钮以 `Other` 元素存在，远程按钮不属于 `com.apple.DocumentsApp` 查询范围。UI 旅程最终采用多元素类型/多进程信号断言选择器出现即止，不做系统表单交互——该段为旅程终点，无需收起。
- 冷启动评审模拟器首轮系统密码提示存在波动（既有现象，非本轮引入），复跑通过；失败日志保留于本轮证据目录之前的运行记录。
- 诚实边界：导出落盘最后一步（复制进用户所选文件夹）未被自动化覆盖——驱动系统文件 App 完成选择在跨进程交互上不稳定；该步骤列入真机人工验收清单。
