# FocalRoom iPhone iOS 本期实施范围

日期：2026-10-27。状态：范围决策，尚未代表代码实现或真机验收完成。

本期只开发和交付 iPhone iOS 客户端。iPad/iPadOS 与 Android 延后，后续是否启动另行决定。该决策调整平台范围，保留原方案中适用于 iPhone 的产品能力与数据安全要求。

本文件是本期执行入口。与 `00_正式实施方案.docx`、`00_正式实施方案.pdf`、`01_MASTER_PLAN.md`、`02_BACKLOG_ACCEPTANCE.md`、`03_ARCHITECTURE_CONTRACTS.md` 的平台范围、任务依赖或发行门禁发生冲突时，以本文件为准；其余业务对象、权限、版本、同步及 Agent 契约继续复用。

## 1. 平台与工程边界

| 对象 | 本期范围 |
|---|---|
| iPhone iOS | 唯一新增客户端；原生 SwiftUI，照片检视和画布按实际性能需要使用 UIKit/Metal |
| iPad/iPadOS | 延后；不做三栏、多窗口、Apple Pencil、PencilKit 专项及平板适配验收 |
| Android | 延后；不建 Android 工程，不生成 Kotlin 客户端，不做 Compose、WorkManager、Keystore 或 Google Play 流程 |
| 现有 Mac | 复用既有应用；仅修改 iPhone 联动需要的资产、同步、权限、渲染版本和 Agent 接口，并完成受影响回归 |
| 现有 Web | 保持既有能力；仅处理共享协议兼容，不启动独立改版或新功能线 |
| 云端与共享领域 | 实现 iPhone 需要的权威写入、媒体授权、同步、Agent、设备管理及权益服务 |

iOS 工程按 iPhone 设备族配置，不启用 Universal/iPad 原生产品范围。最低 iOS 版本和具体支持机型在工程基线核实后确定；无需为延期平台预建目录、适配层或占位实现。

## 2. iPhone 产品范围

底部四入口继续采用 **项目 / Focal AI / 画布 / 消息**，沿用原方案的项目、照片、版本、评论及任务身份。

- 登录、工作区、项目首页、邀请与账户管理。
- 灵感与研究记录、语音入口、PhotosPicker/文件导入、图库、评分与快速选片。
- 单张检视、双图比较、分级缓存、ICC/预览身份和资源所在设备状态。
- Focal AI 持续会话、真实图像观察、工具步骤、授权提示、任务恢复与草案卡。
- 手机画布阅读、缩放、触控编辑、批注，AI 草案比较、部分采纳和撤销。
- 评论、协作权限、消息、版本回流通知、出版物预览与审稿。
- 离线草稿、outbox、同步中心、冲突处理、后台恢复和受限网络策略。
- iOS 购买与权益、隐私控制、数据导出/删除及发行所需的运营能力。

原页面 P01–P07、P09–P14 保留 iPhone 适用部分；P08 iPad Canvas Pro 延后。P07 复杂编辑引导至现有 Mac，P09 使用手机 Bottom Sheet，P11 保留预览与批注。iPad 专属布局和操作不进入 iPhone 验收。

## 4. 契约与实现约束

沿用 `03_ARCHITECTURE_CONTRACTS.md` 的单主权威、稳定 ID、不可变 Rendition、版本检测、幂等回执、事件游标、媒体授权和 AI 草案采纳规则。本期只实施 Swift 原生接口与所需 Rust/TypeScript 契约，Kotlin 示例留作背景参考。

领域规则复用现有纯函数和统一 schema；UI、媒体、存储、传输通过职责明确的接口连接。仅在已有重复或 iPhone 实际调用需要时抽取共享模块，避免为延期平台设计额外框架。Mac 原片默认不上传，iPhone 不得伪造未获授权项目的可访问状态。

本目录是方案包，未包含可构建的 iOS 工程。进入代码阶段应先核实源仓库和固定提交，不能将原文中的仓库审查结果、API v3 或目标目录当作当前已完成实现。

设备测试覆盖所选支持范围内的 iPhone 屏幕尺寸、性能档位与 iOS 版本，并验证 VoiceOver、动态字体、Wi-Fi/蜂窝/离线、后台/杀进程恢复、账号切换和权限撤回。发布流程为内部 iPhone 真机验证 → TestFlight 专业用户测试 → iPhone App Store 发行。

正式数据丢失、越权、未经授权上传、静默错色、双主、AI 未授权正式写入、重复计费、旧版覆盖新版等仍为 BLOCKER。本期交付须分别记录代码实现、服务端集成、真机验收和商店发行证据，不能用范围调整替代完成证明。
