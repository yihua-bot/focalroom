# FocalRoom iPhone 本机导入与双图比较开发记录

日期：2026-10-28，Asia/Shanghai。接续 `05_IOS_DEVELOPMENT_STATUS.md`；该首批记录中的系统导入、双图比较待办已由本轮推进，其余完整计划门槛仍保留。

本轮只开发 iPhone。源码位于 `开发文档/contact-sheet-ai-demo/between-frames/apps/mobile-ios`，继续使用原生 SwiftUI 与本地 FocalRoomCore 包，无新增第三方 Swift 依赖。

## 已实现

- 创建本机项目、图库筛选、单张预览、照片信息与本机选片持久化。
- 实际系统 PhotosPicker 和文件选择器导入；每批最多 20 张，逐张处理，显示进度、重复跳过、失败原因，可取消剩余导入。
- 支持单帧 JPEG、PNG、HEIC、TIFF；单份上限 64 MiB、5000 万像素，暂不支持 RAW、动态图片、多页 TIFF。
- 复制系统提供的所选文件字节，不改写来源。原片与独立预览采用内容摘要命名；两份文件完整保存后，才原子写入项目记录。
- 浏览预览最长边 2048 像素，方向归正，转换为 8-bit sRGB JPEG；不复制来源 GPS 或私密 EXIF 备注，原始文件的元数据保持不变。
- 本机项目按服务和账号隔离。退出清理云端缓存及内存会话，保留本机项目和原片；同服务同账号重新登录后可读取。
- 云端和本机共用双图比较，支持锁定/独立缩放与平移、照片替换、交换和复位；布局按横竖方向调整。原生旅程本轮验证竖屏按钮操作，触摸手势与横屏真实体验仍需真机验收。

## 数据边界与实现原则

本机照片不会自动加入云端共享项目，也没有声称已同步到 Mac。当前 iPhone 正式云端选片仍调用现有 `/api/v2` 权威命令，未由客户端伪造正式版本。

本机目录排除系统自动备份，应用界面和 README 均提示保留来源副本。当前尚无独立离线解锁、导出与迁云入口；账号不可用或卸载应用时的资料取回能力仍需完善，不应将本机项目作为唯一副本。

`LocalLibrary` actor 负责有界文件处理、校验和持久化，`LocalLibraryModel` 协调系统选图、进度与取消，界面只表达项目状态。`PhotoViewport`、`AsyncPhotoPreview` 和 `PhotoComparisonView` 复用于本机与云端，避免重复实现缩放与比较规则。没有为延期平台预建框架，也没有新增迁移、依赖或同步协议；体现 SRP、DRY、KISS 与 YAGNI。

损坏或不匹配的已有资料拒绝继续写入，不静默重建空库；取消保留已经完成的照片。所有文件处理限于所选文件及应用目录，生成素材用于测试，未读取用户正式照片。
