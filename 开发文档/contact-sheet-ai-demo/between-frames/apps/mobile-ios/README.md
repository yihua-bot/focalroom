# FocalRoom iPhone 开发入口

本工程只面向 iPhone，最低编译目标为 iOS 17。使用原生 SwiftUI、UIKit 和系统安全存储，不包含 iPad 或 Android 工程。当前为可运行的开发预览，尚未完成整个 iPhone 实施范围，也未签名发行。

## 已实现

- 账户密码登录、设备 Keychain 会话、重启恢复、本机退出清理及服务端注销。
- 现有云端共享项目读取、搜索、迁移中项目禁用、图库与选片状态筛选。
- 照片授权票据、JPEG 像素摘要核验、受限内存缓存、缩放/平移和预览来源说明。
- 保留/排除/待选正式命令；提交前落盘，超时保留原编号，核对时重放同一命令；版本冲突与权限失败明确显示。
- 按账号和服务隔离的项目资料缓存，离线选片只记录待提交意图，不冒充正式成功。
- 共享画布照片节点阅读与编辑：草案画布可拖动照片节点提交 moveNodes 权威命令（Board 修订乐观锁，冲突自动刷新）；正式/冻结画布只读。文字、笔迹等复杂节点仍以类型标记显示。
- 提案审阅与部分采纳：项目内 AI/协作者提案的待审列表、逐项勾选部分采纳（proposal.apply accepted_operation_ids）或整体驳回；基线过期与权限由服务端裁决并如实提示。已有项目评论与照片定位、已有 AI 评论汇总读取保留。
- Focal AI 文本对话：账户额度展示，与账户 AI（DeepSeek 托管策略）文本问答；消息先按待确认持久化，凭原请求编号经异步提交与回执轮询恢复，不重复发送、不重复计费；项目分析任务与评论汇总阅读保留。
- 从后台恢复时核实项目和权限；项目切换后关闭原项目检视，避免串用照片身份。
- 本机项目创建、系统 PhotosPicker 和文件导入；每批最多 20 张，支持进度、取消剩余任务、重复内容跳过与逐张失败提示。
- 本机 JPEG/PNG/HEIC/TIFF 原始文件逐字节保留，生成独立 sRGB 浏览预览；原片和预览持久化后才写入项目记录。当前单份上限 64 MiB、5000 万像素，不支持 RAW、动态图片或多页 TIFF。
- 本机选片持久化；退出只清理云端缓存，保留账号隔离的本机项目与原片。
- 云端和本机照片共用双图比较：锁定或独立缩放/平移、照片替换、交换、复位，按 iPhone 横竖屏调整布局。
- 本机项目迁云：经现有 `/api/v2` promotions 权威通道上传 2048 像素派生预览与选片快照，原片不上传；迁移幂等可续跑，中断后沿用同一清单字节与服务端项目，不创建重复云端副本。
- 迁云期间与迁云后本机项目冻结写入；完成后云端为权威，本机保留原片作离线存档，可一键打开云端项目继续选片。
- 持久事件游标：按缓存快照 cursor 拉取项目增量事件，仅在出现新事件时刷新权威快照，支持多端提交后的同步恢复。
- 设备登记与撤销：登录后自动登记本机设备（幂等设备键）并绑定当前会话；账户页可查看与撤销设备，撤销立即使对应会话失效。
- 回执查询：UNKNOWN 选片结果按原命令编号先查权威回执，命中即确认已提交，不再重发；仅 404 才允许重发原编号。
- 本机资料离线访问：未登录时经登录页“查看本机资料”按账户只读浏览本机项目，可查看照片与信息、比较、导出；导入、选片与迁云全部禁用并明确标识。
- 项目导出：任意本机项目（含离线只读）可将全部原片逐字节导出到用户选择的文件夹，同名自动去重，附 manifest.json 记录身份、SHA256、尺寸、选片与迁云状态；导出前逐份校验摘要，失败不留半成品。
- 研究资料：云端项目内笔记/链接参考的创建、编辑、删除与列表（复用既有 `/api/v2` research 权威路由）；可选作者/来源/许可元数据，参考为辅助资料，不进入照片资产或正式修订。
- 语音输入：研究笔记编辑器内置设备端语音转写（iOS 26 SpeechAnalyzer），音频不上传；缺资源、无权限或低版本系统时明确提示并回退键盘。
- 同步中心：项目页右上角集中查看各项目的本机缓存（时间/版本）与待提交意图，可跨项目核对重试或放弃未生效选片；离线状态明确标注。
- 云端预览离线缓存：查看过的云端预览按内容摘要落盘（有界 150 份 / 128 MiB、最近使用淘汰、损坏即失效），离线可继续浏览已查看照片；退出登录即清理，缓存不提升任何权限。
- 媒体支持矩阵：JPEG/PNG/TIFF/HEIC × EXIF 方向 1–8 全组合导入与预览归正、超像素上限拒绝的自动化矩阵。
- 版本历史与双版本差异：项目内选择任意两个正式版本对比照片/序列的增删与字段变化（服务端权威 diff 投影，客户端不重放合并）。
- 提案投影预览：提案详情内展示服务端按操作顺序投影的采纳后序列（新增/移除/移动与最终顺序）；基线过期时明确提示采纳会被拒绝、原提案保留。
- 账单目录：账户页展示服务端订阅方案与能力说明；销售未开放时如实标注，不显示虚构价格。

## 本机项目迁云

在已有照片的本机项目中，从右上角菜单选择“迁云到工作区”。迁云会上传每张照片的 2048 像素浏览预览（服务端重新编码并去除 GPS 与私密元数据）和当前选片快照；原片永远保留在本机，不上传。迁移使用服务端幂等迁移键：中断、断网或重启后继续会绑定同一云端项目，不会重复建项；每张预览按内容寻址可安全重传。

迁云进行中与完成后，本机项目的导入与选片冻结，正式修改全部转为云端项目命令（沿用既有权限、版本与幂等事务）。完成前可显式放弃：客户端先向服务端核对迁移状态再撤销未提交副本；云端已提交（SHARED）后不可放弃。迁云不会向其他账户隐式授权，Mac/Web 续接走既有共享登录与权限。

迁云后的本机项目保留原片与预览作为离线存档，随时可通过“打开云端项目”进入权威版本。云端项目在回到前台时按事件游标增量核对，只有新事件到达才重新拉取快照。

## 本机资料离线访问与导出

登录页检测到已登记账户资料时提供“查看本机资料（离线只读）”：按账户列出本机项目，可浏览照片与信息、使用双图比较、导出项目；导入、选片与迁云等写操作被禁用并显示“离线只读”。资料索引（账户邮箱与服务地址）明文保存于应用容器（受设备加密保护），不含任何会话凭据；卸载应用会同时删除索引与资料。

“导出项目”把项目内全部原片逐字节复制到用户经系统文件 App 选择的文件夹（同名自动去重），并生成 manifest.json：每张照片的标识、原始文件名、导出文件名、源/预览 SHA256、尺寸、格式、选片状态与迁云状态，脱离本应用即可核对。导出前逐份校验原片摘要，任何不匹配立即中止并清理暂存目录；导出不改变本机资料。自动化验证覆盖暂存正确性与选择器出现；复制进所选文件夹的最后一步以真机人工验收为准。

## 研究资料与语音输入

云端项目图库右上角进入“研究资料”：项目内笔记与链接参考的列表、新建、编辑与删除，走既有 `/api/v2` research 权威路由（权限、校验与审计均在服务端）；可选填写作者、来源与许可。研究参考是辅助资料：独立身份域，不进入照片资产、选片计数或正式修订，也不随迁云上传。未获编辑权限（如观察者）只可阅读。

笔记编辑器提供“语音输入”：使用 iOS 26 的设备端 SpeechAnalyzer/SpeechTranscriber 实时转写（需要中文语音资源），转写文本先单独显示，确认后并入笔记正文。音频不上传、不保存；无麦克风权限、缺少语音资源或系统低于 iOS 26 时明确提示原因并回退键盘输入。研究资料为在线读取，暂无离线缓存。

## 同步中心与离线缓存

项目页右上角进入“同步中心”：集中列出有本机缓存或待提交意图的云端项目（最近缓存时间、版本号、待提交/待确认/未成功徽标），离线时明确标注；待提交操作可在中心内直接“核对并重试”（沿用原编号，先查权威回执）或放弃未生效选片，不必逐项目进入。

查看过的云端预览会按内容摘要写入按账户隔离的磁盘缓存：上限 150 份或 128 MiB，按最近使用淘汰；文件缺失或长度不符按未命中处理并清理。离线打开项目时，资料快照与已查看预览可继续浏览，未查看的预览仍需联网。缓存只是已授权派生预览的副本，不提升任何权限；退出登录或登录失效时与云端资料缓存一并清除。

## 画布编辑与提案审阅

草案画布在有权编辑时以“编辑模式”打开：拖动照片节点把新位置换算为画布坐标，经既有 `POST /boards/:id/commands` 权威通道提交 moveNodes 命令（schemaVersion 3、Board 修订乐观锁、幂等键）；成功后本地立即反映新位置并推进 Board 修订，他人先行修改返回 409 时自动刷新到最新并明确提示。正式画布仅接受冻结转换、冻结画布只读，与既有生命周期一致。

项目图库右上角进入“提案”：SUBMITTED 提案逐项勾选后“采纳所选”（部分采纳只应用勾选操作，推进一次正式版本）或整体驳回（原提案保留，不改版本）。提案基线与当前版本不一致时服务端拒绝并提示“原提案已保留”，不做客户端猜测合并；审批权限（can_approve）由服务端最终裁决，无权限时只读。

## 导入本机照片

在项目页点击“+”创建本机项目，进入后从“导入照片”选择系统相册或文件。系统相册只授予所选项目的访问权，不要求全相册权限；文件导入在系统授予的范围内复制内容，不更改来源文件。

本机原片、浏览预览与选片记录只保存在当前服务/账户的设备目录，不会自动进入已有云端项目。该目录排除系统自动备份，避免未经同意上传原片；请继续保留相册或文件中的来源副本。退出账户后本机内容保留，重新登录同一服务的同一账户后可读取，其他账户不可见。

本机项目迁云已接入现有权威通道（见上文）。账号不可用时可通过登录页“查看本机资料”离线浏览并导出原片与清单；仍不应把迁云当成备份策略，请继续保留来源副本。

## 打开和运行

在 Xcode 打开本目录的 `FocalRoom.xcodeproj`，选择 `FocalRoom` scheme 和 iPhone 模拟器后运行。Swift package 在本目录本地解析，无第三方 Swift 依赖，无需 XcodeGen。模拟器验证使用本地临时签名；工程已配置 FocalRoom 开发团队，真机与分发仍需要该团队的证书、描述文件和有效 Xcode 账号。

正常登录默认使用与现有桌面客户端一致的工作空间地址。独立部署可展开登录页的“工作空间设置”更改 HTTPS 地址。Debug 构建额外允许本机回环 HTTP；Release 拒绝所有明文 HTTP 服务配置。

## 1.0.0 归档与分发

Release 使用 `studio.focalroom.ios`，Team `KXSFCZF4S3`，版本 `1.0.0`、构建号 `1`；Debug 保留 `studio.focalroom.ios.development`，使测试与正式应用的数据和 Keychain 身份分开。品牌图标集已配置，语音权限文案区分本机音频与确认保存后同步的笔记文字，隐私清单包含所选照片和设备标识用途。

从本目录执行：

```bash
xcodebuild -project "FocalRoom.xcodeproj" -scheme "FocalRoom" -configuration Release \
  -destination "generic/platform=iOS" -derivedDataPath "DerivedData/ArchiveBuild" \
  -archivePath "DerivedData/Distribution/FocalRoom-1.0.0-1-Verified.xcarchive" \
  -allowProvisioningUpdates archive
xcodebuild -exportArchive \
  -archivePath "DerivedData/Distribution/FocalRoom-1.0.0-1-Verified.xcarchive" \
  -exportPath "DerivedData/Distribution/AppStore-1.0.0-1-Verified" \
  -exportOptionsPlist "ExportOptions-AppStore.plist" -allowProvisioningUpdates
```

导出配置为 `app-store-connect` + `destination=export`，只生成本地分发产物，不自动上传。Archive 成功和证书存在都不能替代 IPA 导出与分发描述文件核验；归档可以先由开发证书签名，再在导出阶段使用分发身份重新签名。初始 `No Accounts` 已在用户完成 Xcode 登录后解除；Xcode 27.1 已成功导出 `DerivedData/Distribution/AppStore-1.0.0-1-Verified/FocalRoom.ipa`，实际 Apple Distribution 签名、App Store 描述文件及关闭调试权限均已核验。该 IPA 已包含最新对话滚动修复，尚未上传；详细日志和 SHA256 见仓库根目录 `FocalRoom-v4/IOS_1_0_0_RELEASE_STATUS.md`。

AI 的真实接入在应用中已走服务端托管网关与共用账户额度；确定性模型桩只在隔离验证脚本中注入，不打包进应用。服务状态读取失败时提供重试，未验证邮箱、服务关闭或无可用额度时不提交消息。真实模型调用按用户决定后置，不能把桩测试或公网 401 当作真实模型验收。

本轮公网无会话复核：`/api/v2/health` 为 200，`/api/v2/ai/account` 和异步结果的完整路径为 401，设备列表为 404；AI 路由存在，但供应商凭据、账户额度及移动端新增契约的生产集成仍需登录后核实。生产升级方案见仓库根目录 `FocalRoom-v4/IOS_1_0_0_PRODUCTION_UPGRADE_PLAN.md`，未执行生产迁移或部署。

## 本地验证

以下命令从 `between-frames` 工程根目录运行。复用既有 Node、PostgreSQL 测试依赖；脚本只在 runner 创建的回环临时数据库内工作，不读取用户库、原照片、生产凭据，不调用真实邮件或模型。

```bash
swift test --package-path "apps/mobile-ios" --filter 'CoreTests.CoreTests|LocalLibraryTests|MigrationStateTests|ExportTests|PhotoTransformTests'
node "apps/api/test/run.mjs" "apps/mobile-ios/scripts/verify-live.mjs"
```

原生界面验证需要已安装的 iOS Simulator runtime。创建独立评审 iPhone，不修改或清空用户现有模拟器：

```bash
device_id="$(node "apps/mobile-ios/scripts/create-simulator.mjs")"
xcrun simctl boot "$device_id"
FOCALROOM_IOS_SIMULATOR_ID="$device_id" node "apps/api/test/run.mjs" "apps/mobile-ios/scripts/verify-live.mjs" --ui
```

界面验证使用生成色块、演练账户和真实 NestJS/PostgreSQL 接口，覆盖登录、图库、实际预览、选片、评论、画布、已有 AI 结果入口，以及本机项目、系统相册选择/去重、系统文件选择、双图锁定/独立缩放、重启与退出。脚本仅向独立 FocalRoom 评审模拟器添加生成的测试图片，并将生成文件放入该评审 App 的 Documents；不导入用户照片。结束时检查实际本机文件的 SHA256 与云端项目照片数，不能只凭界面提示判定成功。

Swift 集成验证额外模拟“服务端已经提交但客户端丢失回执”，核对重试后只有一个正式版本，并验证 Viewer 被服务端拒绝写入。核心测试验证四种格式、方向、来源元数据保留、预览去除 GPS/私密备注、损坏/超限/取消保护和账号隔离。

证据保存在 `test-results/focalroom-pg-tests-*/`，包括 `ios-verification.json` 和 `iPhone-UI.xcresult`。SwiftPM 与 Xcode 每轮使用独立构建目录，界面验证应使用专用评审模拟器，避免并行会话卸载同一测试应用或锁住 build.db。结果未确认或测试跳过时不能按成功验收；脚本还核对实际数据库的正式版本数，避免只凭 `xcodebuild` 退出码判断通过。

如需交互评审，可启动独立测试服务：

```bash
node "apps/api/test/run.mjs" "apps/mobile-ios/scripts/verify-live.mjs" --serve
```

脚本打印的回环地址与演练账户仅适用于这次临时环境。在模拟器登录页“工作空间设置”填写该地址后登录。临时数据目录会保留供复核，不能用于正式用户数据。

## 契约与边界

当前接入真实 `/api/v2`，没有假设方案中的 `/api/v3` 已上线。现有画布命令自身的 `schemaVersion: 3` 也不代表 API 已升级到 v3。正式写入只复用后端权限、版本与幂等事务，不在客户端自行递增正式版本。

网络层、DTO 和账号缓存放在 `Sources/FocalRoomCore`；界面、会话协调及 Keychain 适配在 `FocalRoom`；后端联调与原生界面测试分别在 `Tests`、`FocalRoomUITests` 和 `scripts`。共用一套现有业务契约，不为延期平台预建框架。

云端预览不代表原片像素或专业 ICC 验收；查看过的云端预览落盘为按账户隔离的有界缓存，未查看的仍需联网。本机项目的原片与浏览预览另行持久化，浏览预览转换为 sRGB，不改写原始文件。画布中的复杂文字、笔迹、连接与分组暂以类型标记显示。Focal AI 为文本对话：照片观察需另行逐次授权（服务端校验图像同意头与 1400px 派生预览），当前未接入图像输入；验证环境使用确定性模型桩走真实协议面，真实模型质量未测。

隐私清单按当前登录标识与选片数据用途声明；文件元数据读取范围仅限应用容器，依据 [Apple 文件元数据访问理由](https://developer.apple.com/documentation/bundleresources/app-privacy-configuration/nsprivacyaccessedapitypes/nsprivacyaccessedapitypereasons) 和 [数据类型声明](https://developer.apple.com/documentation/bundleresources/app-privacy-configuration/nsprivacycollecteddatatypes/nsprivacycollecteddatatype)。发布前仍须按最终功能和服务端实际行为复核。
