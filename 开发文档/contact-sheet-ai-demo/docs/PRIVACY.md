# 隐私与数据说明

适用：FocalRoom 桌面版（含 v1 历史能力与已落地的 v2 增量）。最后更新：2026-10-17；包含本地作者记忆、实际服务图像授权和同端点模型分工。

## 你的照片

- 原始照片**永不修改、永不复制、永不上传**：应用只保存只读路径引用与本地缓存（缩略图/预览）。
- 删除项目是归档（可恢复）；没有自动删除原图的入口。
- 源文件移动或丢失后，编辑历史保留，可通过重新链接恢复关联。

## 云端图像（需要你逐次明确授权）

- 默认**零上传**：本地 Mock 与全部选片功能不发出任何图像。
- 视觉任务需要授权（仅本次任务 / 本项目可撤回 / 禁止云端三档）；授权后仅上传**最长边 1400px 的重编码 JPEG 预览**（不含 EXIF/GPS 定位）。
- 单次授权绑定一个任务及实际观察服务端点/型号，后续任务需重新授权；项目授权只供同一图像收件人后续任务使用。更换实际观察端点或型号需重新明确授权，轮换同一服务的密钥不改变收件人；旧通用 openai 正向授权不会自动升级。
- 可配置同一服务的策展与图像观察两个型号：图片只发给观察型号，观察事实会作为任务上下文交给策展型号，应用的观察缓存与草案保存在本机。授权卡明确显示此数据流，不保证服务端删除数据。不同端点不能借模型分工自动转交；完整跨服务授权/回退尚未实现。两角色变化要求旧任务重新委托；新任务只更换策展型号且图像收件人不变时，可沿用该观察型号的项目授权。
- 发出请求前预留授权配额。成功响应按传输张数结算；断网、超时或中断导致结果不明时保留预留，不能视为零上传，也不会自动重传。模型返回的虚构照片引用会被丢弃。
- 「模型与密钥 · 诊断」→「管理图像授权」可主动撤回；「禁止云端图像」会撤回本项目全部服务授权，服务未配置或配置失效也可操作。重新批准一个服务不会恢复其他服务；取消操作不改变授权，也不发起任务。撤回阻止后续发送预留，不能撤回已发送/已进入预留的请求。观察结果缓存在本机，同一服务/型号的有效缓存可复用而不新增上传。
- 授权卡显示实际服务地址和型号；界面过时的收件人标识会被后端拒绝。HTTP 自动重定向关闭，不会按 Location 自动转发图像，但应用无法保证服务端内部的数据处理。
- 云端处理遵循你所配置模型服务商的数据政策；应用不宣称服务商会删除其侧数据，请在服务商处核对。

## API 密钥

- 密钥存入 macOS 钥匙串（或开发用环境变量 `BETWEEN_FRAMES_OPENAI_API_KEY`）；不写入应用数据库、日志或前端。
- 界面仅显示脱敏尾号；「移除钥匙串密钥」即刻删除。
- 运行中的模型客户端在应用重启后切换密钥；显式空环境变量会禁用真实 Provider，并且不回退读取钥匙串。

## 本地数据与导出

- 全部权威数据（项目、决策、事件、草案、任务、证据、假设）存于本机 SQLite；无遥测、无账号、无云端同步。
- CSV/JSON 导出默认**不含本地路径**；你主动填写的备注与意图按原文导出。接触印相 HTML 含缓存缩略图。
- 印刷参考是包含缓存预览的 HTML，可打印为 PDF；侧车在所选父文件夹中新建目录，仅含编辑元数据。
- 偏好证据保留为审计记录；可排除/恢复其参与学习，假设可确认、纠正、停用或可恢复地移除。排除后会重算支持与反例，已纠正或移除的假设不进入新任务检索。
- 记忆控制变化会暂停执行中的任务，并要求重新委托；不会删除原图或改变正式选片。
- 物理删除已提供：可删除单条证据或假设（不可撤销，删除的假设不会从剩余操作中重新生成）、清空本项目的视觉观察缓存及其本地语义检索缓存（云端已上传数据不受影响，再次观察需重新授权）。本地句向量保存在应用缓存目录，包含观察摘要、照片标识摘要和派生向量，不保存原图、观察原文或查询文本；向量仍可能透露内容信息，不是匿名化或加密。缓存每项目最多500条/8MiB，损坏或版本不兼容会重建；原观察被更改/删除后不可通过旧向量找回，未再次访问的旧派生条目可能保留至淘汰或主动清空。命令历史回执、数据库备份与旧快照仍可能保留删除前的记录——删除不宣称清除所有历史副本或进程内存。
- 跨项目记忆默认关闭；Memory Studio 可明确授权离线 Agent 引用其他活跃 LOCAL 项目已确认且有有效证据的相关假设，附来源项目与支持/反例引用。共享/迁移中/归档项目和云模型不参与；当前桌面按单一本地作者处理，尚无多 Creator 隔离。更改授权会暂停正在执行的任务；授权撤回或来源变更后旧任务需重新委托。关闭不清除已保存的历史上下文、回执或备份。FTS5 不向外部服务发送内容。旧库升级前会保存含已提交 WAL 的完整性校验备份。

## 诊断信息

- Agent 面板 →「模型与密钥 · 诊断」→「查看本地存储与诊断」先显示应用版本、全库计数、提供方就绪状态与文件大小；可检查 JSON，再主动复制到剪贴板。不会自动上传或发送。
- 统计仅覆盖固定应用数据目录中的数据库、WAL/共享内存、平面图片缓存和迁移备份，不读取原图内容、不遍历导出目录、不跟随符号链接。不含文件名、项目名称、密钥、端点、本地路径或备注文本。
- 文件体积是读取时的逻辑大小，不是物理磁盘占用、原子快照或备份可恢复性保证。不可读/跳过条目与扫描上限会标为不完整，数量读取失败不会显示成 0。诊断不清理文件或修改项目。

## 已知边界（如实说明）

- 桌面构建未签名/公证（Beta 前完成）；钥匙串写入瞬间密钥出现在本机进程参数中（单用户桌面场景的已知权衡）。
- 卸载应用不会删除你的项目数据库与缓存（位于应用数据目录），也不会动你的原图。
