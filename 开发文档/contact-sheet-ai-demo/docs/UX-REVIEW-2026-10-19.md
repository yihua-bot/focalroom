# FocalRoom 交互评估与修复记录

日期：2026-10-19。基于工作树起点 `2702f91` 的实际代码、正式本机数据库只读核对、浏览器与隔离原生应用验证。本文不是 M0–M5 全量完成声明。

## 产品结构

项目列表是全局入口。先打开或创建项目，再进入选片工作台、AI 智能选片、作品序列；偏好记忆也是当前项目的功能。照片详情只承载当前照片的信息、人工决定、评分及备注。

AI 使用独立导航和独立标题，保留照片画布作为选择上下文，不再放在照片检查器的第二个 Tab 中。未打开项目时，不展示上一个项目的功能入口。

## 正式演示与开发数据的边界

用户明确要求保留面向用户的演示项目，最终实现如下：

- 内置一个「第一次散步 · 演示项目」，12 张照片，通过正式导入与人工编辑链路使用。
- 创作意图为冬日影像选 8 张，围绕雪地光线与动物自然状态编排作品；AI 表单预填项目自身的创作意图与数量。
- 演示只创建一次。已有用户项目时也能补齐；演示被改名、编辑或归档后，不覆盖、不复活、不重复创建。
- 无演示资源时不留下空项目；打包资源检查确认只有这 12 张内置照片。
- 正式桌面入口不导入浏览器 MockRepository，旧浏览器预览的 28 张素材不进入桌面前端产物。独立浏览器开发预览继续可用。
- 演示不会自动委托 AI。登录、账户额度及照片上传授权仍按真实服务执行，演示数据不绕过这些条件。

正式本机数据库曾包含一个「M1 原生验收 · 示例派生图库」项目，200 张照片均来自临时目录 `between-frames-m1-*/fixtures`。已先用 SQLite backup API 备份，再通过已安装客户端的归档流程处理；原图、备注、历史和恢复入口均保留，未清空数据库或按标题批量删除项目。
