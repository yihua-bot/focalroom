## 本轮实现

- 原生桌面入口改用 FocalRoom 登录会话调用固定 DeepSeek 服务；不读取开发机模型配置，用户无需填写 API Key。
- 服务端新增账户额度、并发预留、真实用量结算、请求去重、异常结果保留和人工对账工具；默认赠额 0，尚无支付/套餐。
- 桌面显示可用/预留 tokens，未登录、服务关闭、邮箱未验证和无额度均不能委托；登录事件清除账户缓存，余额定期及手动刷新。
- 图像请求仍需原生 scope 和授权，服务端再次验证 JPEG、1400px 边界与去元数据；明确 FocalRoom/DeepSeek 两个接收方。
- 账户绑定进入任务、授权和缓存身份；换号/退出不能续跑旧任务。账户令牌不传给 DeepSeek，供应商密钥不传给客户端。
- 本地诊断接受账户服务来源，并继续过滤所有密钥/会话字段。

实现依据见 [ADR 0044](ADR/0044-hosted-deepseek-account-quota.md)。全部新迁移尚未作用于生产。

## 原生最终验收

独立 `studio.focalroom.aireview` debug app 已构建并实际打开，新建空项目、打开编辑建议后显示 `FocalRoom AI · DeepSeek`、未登录提示、刷新额度，委托按钮禁用。未把账户服务误显示为演示已运行。
