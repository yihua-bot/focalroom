# 出版页面与文字编辑 · 2026-10-25

## 范围和状态

接续创作工作区交互打磨，推进最终计划 H1 的实质编辑能力。实现位于独立工作区 `focalroom-publication-versions/film`，基于1ed5581及既有出版/工作区增量；本轮没有合入主工作区、提交、推送、安装或发布。完整目标保持有效，不能以这批实现代替全部 G0–G8、Focal AI v2 与 v3.1 完成。

## 用户可完成的操作

1. 在当前页后插入空白页，指定毫米尺寸、页边距和出血；空白摄影书也可以先建立封面。
2. 调整已有页面尺寸；在保存前检查已有照片框和文字是否仍处于页面及出血范围。向前/向后移动内页，自动连续编号并更新左右页。封面固定在开头，已有封底保持末尾。
3. 二次确认后移除内页，明确说明照片框与文字一并移除；内容仍保留在此前的不可变版本中，恢复版本可以恢复原来的页面和内容身份。
4. 添加/编辑/移除文字框，调整毫米位置和尺寸、pt字号、衬线/无衬线/等宽字体族、行距、对齐、颜色和粗体；输入先在小版面中预览，明确保存后才写入。
5. 添加动态页码；页码随排序变化，封面/封底不显示数字。文字按实际页面预览宽度缩放，不把字号固定为屏幕像素。
6. 正式页面里点击文字框继续编辑；历史版面保持只读。未保存退出有明确放弃动作或确认，待确认请求只返回主编辑器确认原请求，不声称关闭等于撤销。

所有新增入口、表单、删除确认和反馈有中英日韩文案，复用现有设置选择的语言。

## 保存、恢复与权限

新增操作接入已有 PublicationCommandRequest、持久请求队列、人工命令入口和同一事务；没有添加新的无审计写入口。页面顺序必须是本书完整、不重复的页面集合，封面/封底不被移动到中间；先临时腾出唯一页码，再在同一事务内编号，避免交换页码造成唯一约束冲突。插入、删除和排序共用编号过程。

文字的页面关联在数据库内核对，不允许写入其他出版物；新增内容使用固定ID，重试原请求不重复插页、文字或历史。有限字体族、颜色、字号和行距均校验，正文作为纯文本渲染，不执行HTML。几何校验继续由版面领域在提交前完成；任一步无效，版面、历史、回执全部回滚。

权限、项目状态、出版物状态、旧版本冲突和幂等边界沿用原入口，不绕过为 Agent 开放正式写权限。本轮无新增数据库迁移或依赖，使用既有 pages/texts 表和上一批已在临时库验证的0033历史机制。生产数据库未连接或更改。

## 未完成与后续

H1仍是部分完成。文字目前为受控纯文本和基础段落样式，不是完整富文本、字体嵌入或排版引擎；跨页编辑、母版、章节/封面/书脊设计、网格标线、自由添加/移除照片框及字体溢出预检仍待推进。现有文字渲染是屏幕版面预览，不承诺不同系统字体一致或印刷级输出。

H2/H4/H5/H6的高分辨率像素冻结、生产Edition、PrintContract、字体/ICC/PPI/出血预检、PDF/X和实际样书仍未完成。页面与文字进入了可恢复的版面历史，不等于已经完成这些交付。A–K其余未完成项继续沿用最终计划清单；真人、硬件、印厂验收后置，不以模拟代替。
