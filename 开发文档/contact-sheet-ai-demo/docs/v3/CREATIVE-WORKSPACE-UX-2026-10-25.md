# 叙事画布与出版物交互打磨 · 2026-10-25

## 范围

根据用户要求继续改善两个创作工作区。源码位于独立工作区 `focalroom-publication-versions/film`，没有覆盖持续变化的主工作区，没有提交、推送、部署或替换已安装客户端。本报告接续 WORKSPACE-UX-AND-PUBLICATION 与 CANVAS-PHOTO-CLEANUP；不把这轮界面改进计为完整 v3 或发行完成。

## 叙事画布

- 工具按选择/便签/连接/画笔、撤销/重做、选中项操作分组；没有选中内容时不展示无效的分组、锁定、移除操作。
- 画布使用工作区剩余空间，缩放和适合窗口固定在底部；普通滚动平移，Ctrl/Command 滚动在指针处缩放，按钮在画布中心缩放，百分比按钮回到100%。
- 模式按钮显示当前状态，Escape 结束连接/画笔和当前手势；Ctrl/Command+A 在画布内选择可见内容。照片、便签和分组增加键盘焦点、名称及 Enter/Space 选择。
- 分组名称和右键评论使用应用内对话框；名称、评论分别遵守既有50/5000字限制。评论写入成功后即关闭，避免刷新失败误导用户重复提交。
- 新加照片、便签避开已有可见内容；不会移动或清空旧布局。沿用照片去重、移除确认、锁定保护、批量原子命令与撤销重做。
- 操作提示随选择、连接、画笔或只读状态变化。选片快捷键仍限制在选片工作台，不串入创作工作区。

## 出版物

- 新建摄影书有明确标题和后续动作提示；创建后定位到新卡片。每本书的每页照片数独立，避免一本书的设置影响另一本。
- 默认侧栏是页面缩略图，版本记录按需切换。缩略图每批最多40页，支持分页；从下拉列表跳到远页时同步对应缩略图批次。
- 上一页、下一页、页码与下拉选择构成同一导航；当前页和选中的照片框明确标记。
- 位置/尺寸与照片裁切分组排版；修改先预览，明确保存后才写入。无效位置、尺寸、裁切焦点和放大倍数在本地提示，不发送无效命令。
- 尚未保存时标记状态并阻止切页，保留明确的保存/放弃动作和关闭确认。命名保存后切到版本记录，继续沿用不可变历史、并排比较、确认恢复与原请求确认。
- 页面预览按可用高度与页面比例缩放，减少底部截断；较窄窗口允许工具重新排布。缩略图不嵌套按钮，侧栏页签支持键盘切换。
- 新增文案提供中英日韩。普通用户界面不增加测试、迁移或内部实现说明。

## 回归发现

真实本地审稿旅程发现：上一批新增照片标识后，画布比较与历史补偿预览的两条照片来源查询未返回 `photo_id`，引发数据库解码失败。本轮补齐同项目 alias 关联，并增加资产编号与照片编号不同的实际数据库回归。没有更改数据库结构或放宽权限。

初轮新增浏览器用例以标签定位画布时同时命中侧栏按钮与画布；已限定在主工作区。初轮 Rust 测试夹具尝试改变已经冻结的节点来源，既有不可变约束正确拒绝；改为建立新的合法照片节点及来源记录，没有修改生产约束。所有首轮日志和失败 trace 保留在本轮证据目录。

旧画布首次回归在实时画笔预览切换到持久笔迹时取得零尺寸。用例改为先确认真实 Store 已保存 ink，再等待持久 SVG 的非零绘制视口；没有修改产品渲染或取消尺寸断言，完整4项复验通过。前端首轮两项测试仍默认直接查找历史版本按钮，已改为先切换到新的“版本记录”页签。

## 实现原则

沿用现有 Repository、命令队列和事务约束；UI只补导航、状态与操作反馈，不重复实现持久化。照片放置避让为单独纯函数，页面导航独立组件，缩略图复用版面渲染，避免双套布局逻辑。边界校验前后端同时保留；可见预览不冒充正式出版文件。
