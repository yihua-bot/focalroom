# FocalRoom 账户、登录引导与订阅交付记录

日期：2026-10-22。代码基线：`9795d40616d59801300bb1b4c042db441d2866f8` + 当前工作树修改。本轮没有提交、推送、生产部署或发布客户端。

本轮完成账户菜单、按场景登录引导、桌面/Web 订阅界面及可离线验证的支付后端链路。**这不代表已开放正式收费，也不代表 v3 全部 Gate 完成。** 正式价格、额度与支付渠道尚未收到确认；销售默认关闭。此前 H0 补修另见 `H0-FOLLOWTHROUGH-2026-10-22.md`。

## 1. 用户现在会看到什么

### 左下角账户菜单

- 保持常驻头像入口；未登录显示「未登录」，有头像时使用头像，无头像使用昵称首字。
- 展开后显示昵称、实际套餐、邮箱，分组提供「剩余用量」「订阅与账单」、资料修改、设置、帮助、联系作者、退出登录。
- 套餐来自服务端账户结果，不以本机标记冒充付费状态。
- 支持方向键、Home/End、Escape、返回触发按钮；较矮窗口内菜单可滚动。
- 参照用户提供的 Codex 账户菜单组织信息，不添加与摄影产品无关的菜单项。

### 按需要登录

| 功能入口 | 未登录行为 | 登录后行为 |
| --- | --- | --- |
| AI 智能选片，含快捷键、快捷指令、比较/排序入口 | 说明为什么需要登录，由用户点击「继续登录」后打开浏览器 | 返回原入口，打开选片抽屉；不会因打开抽屉就开始分析或上传 |
| 发送 AI 选片消息 | 重新确认当前登录状态 | 继续现有任务委托、额度检查及预览范围绑定 |
| 邀请他人审稿 | 显示审稿与权限管理的登录原因 | 仍须明确选择共享预览并点击开始共享；登录本身不上传 |
| 订阅、剩余用量、账单 | 可浏览方案；读取私人资料/付款前要求登录 | 显示该账户的状态、余额与账单；不会登录后自动购买 |
| 演示项目、本地导入、人工选片、作品序列 | 继续可用 | 保持本地工作流程 |

登录弹窗说明照片留在本机、登录不会自动上传；可暂不登录或取消等待，取消会清除待恢复动作。过期会话不会被旧的界面状态误判为仍然登录。登录弹窗、订阅弹窗均覆盖 AI 抽屉，避免弹窗被挡住。

### 订阅界面

桌面账户菜单及 Web 账户菜单均接入相同订阅组件，提供中、英、日、韩四语：

- 基础版 / FocalRoom Pro 比较；月付 / 年付；金额、币种及额度读取服务器。
- 基础版不虚设协作付费墙；Pro 的差异为额外 AI 用量。已有额度依然由原账户账本核算。
- 剩余百分比、可用点数、当前方案、有效期/续费日期。
- 账单日期、金额、状态；跳转支付服务的账户管理页处理付款方式、账单与取消续费。
- 网络异常、销售关闭、无额度、无账单、待确认付款等状态。
- 未付款可以取消本次付款；重新打开页面后仍能发现并取消待完成付款。
- 付款返回只触发重新查询，不能凭网址参数或点击按钮开通订阅。
- Web 支付返回地址 `/shared#billing=return` / `canceled` 打开账单界面；返回标记不作为成功凭证。

销售配置缺失时显示「订阅暂未开放」，付款按钮不可用。验收截图中的美元价格与额度均为隔离夹具，**不是 FocalRoom 正式定价**。

## 2. 文案清理

- 共享操作改为「开始共享」「继续共享」「取消共享」，移除界面的 API/Web 服务地址输入。
- 账户入口使用「登录」，不使用「登录云端」或授权协议说明。
- 存储页面显示项目数据、照片预览、备份占用，移除数据库/WAL/迁移/Provider 与原始诊断 JSON 面板。
- 保留「复制支持信息」；内部支持资料仍可包含实现字段，不直接展示给普通用户。
- 提案面板不再让用户填写审批 nonce；仍使用当前提案绑定的审批凭据，不降低后端校验。
- 提案照片显示文件名，作者显示人类可读名称；结果显示「已采纳 N 项调整」。
- 活动记录、浏览器演示提示、AI 服务变更提示及多语言预置文案已相应调整。
- 常见底层异常统一转换为可操作提示；实现信息保留在错误原因中供排查。
- 内置演示项目保留。用户自行创建的项目标题、照片文件名和创作内容不做擅自改名。

## 3. 实现与边界

主要入口：

- 桌面：`src/features/cloud-login/AccountProvider.tsx`、`LoginDialog.tsx`、`CloudLoginView.tsx`。
- 订阅：`src/features/subscription/SubscriptionDialog.tsx`，共享类型位于 `packages/contracts/src/billing.ts`。
- Web：`apps/web/src/shared/BillingDialog.tsx`、`SharedApp.tsx`。
- 桌面桥接：`src-tauri/src/billing.rs`、`cloud_auth.rs`、`commands.rs`；JS 不接触登录凭据或原始支付 URL。
- 服务端：`apps/api/src/billing.ts`、`billing-gateway.ts`。
- 迁移：`apps/api/migrations/0019_subscriptions.sql`，仅在隔离测试数据库执行，未迁移生产库。

`BillingGateway` 隔离支付协议，目前只有可选 Stripe 适配器。它使用固定官方地址、固定 API 版本、严格支付地址限制；接口密钥只在 API 服务端。该实现不代表已经确定商业支付渠道或开通商户。

新建付款时校验真实 Price 与展示配置一致。先持久化付款意图，再调用支付平台；未知响应重试沿用同一请求身份，避免重复订阅。不同账户之间不能查看账单、操作管理会话或取消对方付款。

订阅/账单由验签通知与支付平台当前状态核对。事件与账单均去重；已支付的首期/续期账单在同一事务中发放 AI 额度。订阅通知本身不发放额度，重复通知不重复发放；过时事件不能覆盖更新状态。暂停/未完成订阅不显示虚假的续费承诺，也不发放额度。

生产 Compose 增加下列配置透传，样例保持关闭且不含凭据：

- `FOCALROOM_BILLING_ENABLED=0`
- `FOCALROOM_STRIPE_SECRET_KEY`、`FOCALROOM_STRIPE_WEBHOOK_SECRET`
- `FOCALROOM_BILLING_PRICES=[]`

价格条目结构为 `id / interval / amount / currency / includedTokens`；金额为对应币种最小单位，界面使用「点」显示 AI 用量，当前换算为 1000 tokens/点。月付、年付的周期、金额、实际 Price 与额度须一致；年付额度当前在年度账单支付后一次发放，未实现按月拆分发放。免费/补赠额度与已发放余额目前不会因取消订阅自动清零。这些规则必须由产品方确认后才能开放销售。

即使配置支付，未配置 FocalRoom AI 服务也拒绝销售。只关闭新销售并保留有效支付配置时，已有账户仍可查看账单和管理订阅，已签名通知继续处理；不要把清除支付凭据当作暂停销售的方式。没有选择其他服务商的自动回退。

## 5. 正式收费/发布仍需要完成

1. 确认商业方案：币种、月/年价格、额度、续费、年付发放、取消后余额、退款、争议/拒付规则及对用户的条款。
2. 确定可用支付渠道和商户；若选择 Stripe，完成真实商户 Price、Portal、回调配置及测试环境联调。目前不支持微信/支付宝原生订阅，不能宣称已接入。
3. 补齐已确定政策所需的退款/拒付额度处理、账务补偿/人工核对工具。当前只实现正常订阅与续期链路，不能把未知付款结果超过 23 小时的阻断提示当作已经实现自动对账。
4. 验证真实首付、续期、失败重试、取消续费、退款/争议、平台通知重试及账单金额/额度一致性，再开启销售。
5. 取得生产变更授权后备份数据库、迁移 0019、部署 API/Web、配置服务端凭据，检查生产返回地址与登录状态。本轮未执行任何该步骤。
6. 用新源码构建正式候选，补验 macOS 真机登录、浏览器支付返回、钥匙串及账户切换；重新签名、公证和验安装包，然后才能替换官网下载。

此前 v3 中的原生色彩、真实修图软件往返、出版输出与完整 Gate 验收等剩余任务不因本轮账户功能完成而自动关闭。
