# v2：DeepSeek 实测、任务身份与真实 token 结算

日期：2026-10-16。起点 `6f17e20`，执行期间工作区被其他提交推进到 `83f80e2`，均保留；以本报告最终源码指纹为准。本轮推进现有 M2/M3 的真实服务验证，不宣称 M3 整体完成，也未开始新的云共享服务。

## 修复与边界

- **任务身份**：模型请求现在明确提供后端生成的任务 ID。`finish_task` 原先要求该 ID，却未在请求中提供，模型无法可靠提交。新增本地 HTTP 完整旅程只从线上请求/工具回执取项目、任务、草案身份，验证 `list → create → finish → review_ready`，正式项目投影不变；没有直接读取测试 Provider 内的 Task 来替模型补 ID。
- **工具批次**：不再静默丢弃无法解析的工具调用。缺调用 ID/名称、非对象参数、坏 JSON，以及提供方标记 failed/incomplete 的响应，都在执行前拒绝，不能执行其中的有效子集。HTTP 200 的错误对象同样拒绝；上传已经发生时仍保留计量。
- **错误脱敏**：外部错误正文可能回显 Authorization；现只返回 HTTP 状态，不将正文写入任务/步骤。回归以合成假 key 复现并锁定泄漏修复。真实凭据没有写入源码、数据库、日志、报告或钥匙串，只传给测试子进程环境；归档输出再次脱敏。
- **实际 token**：`ModelProvider.generate_metered` 为旧 Provider 提供默认兼容实现。真实适配器校验输入/输出/总数一致后返回计量，按轮写 `model_usage_reported` 来源记录，并结算已有预留；缺分项时仍保守预留，不伪造实际分项。输出 token 包含提供方计入的推理 token。超输出、总量或费用时，在执行工具前暂停；缺失或矛盾计量拒绝且保留预留。
- **有效预算**：模型上下文现在包含任务预算与服务档位取小后的有效上限和剩余额度，请求前预留与响应后结算均受同一上限约束。提示版本 `m3-openai-2` 要求按目标调用工具、及时提交已满足目标的草案。旧版本检查点不能直接续接新提示，需重新委托；未升级原用户库。
- **回归稳定性**：全量回归发现媒体链接的两项测试会相互移除同一进程环境变量，已按现有视觉测试方式加互斥锁；不改变媒体签名业务实现。

复用原有 schema、授权、预算、事务与步骤表，无新依赖或迁移。费用仍使用现有保守系数：**实际 token 不等于实际账单金额**。UI 的旧 `inputEstimate/outputEstimate` 字段为兼容保留；提供方实测来源须以 `model_usage_reported` 为准，旧/混合记录不能直接宣传为全量实际计费。

实测后最后补强了“缺完整计量不退款”的兼容分支，使用离线完整回归验证，没有为该分支重复调用付费服务；上述 DeepSeek 成功运行使用完整计量路径。请求模型名为别名，不作为不可变供应商模型版本证明。

## 真实服务验收

用户已确认密钥属于深度求索。使用官方 `https://api.deepseek.com/responses` 与 `deepseek-flash`；该端点、输入图像、结构化输出和用量字段见 [官方 Responses API](https://api-docs.deepseek.com/api/create-response/)，模型图像能力见 [官方视觉文档](https://api-docs.deepseek.com/guides/vision/)。没有将凭据发往其他服务。

| 独立场景 | 结果 | 实测证据与限度 |
|---|---|---|
| 按文件名升序取前两张 | **pass** | 6 张本地生成 PNG；3 轮模型请求、4 次工具调用，提交 1 份含 real00/real01 的草案并进入 review_ready；ID、顺序和正式项目完整投影均断言。实际总 token **13,021**；费用保守估算 **15 美分**，不是账单。没有上传图像。 |
| 单张视觉 Provider 协议 | **pass** | 120×90 的生成红色 JPEG；准确 photo_id、合法结构、非空事实数组、实际 **799 token**。输出上限 4096 包含推理 token。只证明 Provider 协议，不替代引擎 consent/缓存旅程或摄影质量。 |
| 原始开放选片目标 | **未通过** | 调试运行 4 次，均在预算保护下 paused，不能记为成功。最终修复版本仍在 4 轮/7 工具调用后暂停，已有草案但没有最终提交；报告用量 17,246 输入 + 2,575 输出 token，费用保守估算 23 美分。剩余额度不足下轮保守预留。 |

原始开放目标是“从六张图形成两张草案，不判断色彩”。文件名任务是**另外一个目标更明确的场景**，没有将它替换为原任务的修复成功证据。四次调试并非四项独立质量样本；上述生成素材也不能充当规定的授权摄影师数据集。没有提高预算、自动完成任务或放松 `review_ready` 断言来换取通过。

## 剩余与下一步

**首要缺口仍是开放选片的预算内收敛**：减少无关检索、测量上下文/工具载荷、改善完成草案后的提交策略，并保留预算拒绝，不能通过自动提交或抬高额度掩盖问题。当前保守预留可能在实际已用额度较低时暂停，这是已知限度。

随后建立至少 30 个授权任务、每项 80–300 张照片的分层评测，记录五维独立盲评、视觉事实错误、完成率、实际修改和成本。提供方 token 已可追溯，模型价格/缓存折扣/账单校准尚未实现。桌面模型端点/模型配置 UI、Creator 私有记忆、云身份、共享权威、实时协作与正式支付仍待后续工程；本轮不改变总账验证层级，也不把两项真实协议验证称为 M3 质量完成。
