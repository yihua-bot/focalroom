# M3 本地语义照片候选检索验收

日期：2026-10-17（Asia/Shanghai）。范围：M3 的只读缓存事实语义检索及现有云切片回归修复。M3 整体保持 partial。

## 本轮交付

新增 `search_photos_semantic`：在任务允许的照片中，用 macOS NaturalLanguage 的真实本地句向量对已有 `visible_facts` 排序，带回照片 ID、观察记录/模型/缓存版本、实际引用事实和相似度。原 `search_photos` 字面检索保留；无缓存、缺模型、不支持语言、工作槽忙或时间不足时明确回退。语义相似度不代表事实可信度、审美评分或相关性通过。

每次最多 500 张、每张前两条各不超过 400 字的事实、两个并行工作槽、最长 3000ms 协作式计算预算。向量在写事务外生成，写入工具回执前重新校验任务、调用指纹、范围和完整观察内容摘要。取消不产生迟到回执；同 call_id 重放不重复计工具次数。向量不落盘，不读取图像或新增上传，不生成偏好证据。

实际调用 Apple 模型的中文和英文近义测试通过：中文 revision 1 / 640 维、英文 revision 1 / 512 维；“骑两轮车的人”等字面不命中的描述可找到自行车事实。测试使用生成图片和合成缓存事实，不计 LUMIX 真实摄影质量任务。只使用已有本机模型，没有请求下载模型资产或新增外部供应商。

云侧回归发现并修复：新协作模块的私有错误类型导出和四个未 await 的广播 future 导致严格 Clippy 失败；Viewer 可以创建评论。新增 Viewer 写评论的测试先实际失败（200 而非 403），修复统一动作权限后通过，并检查零评论写入以及提案/审批/resolve 拒绝。原测试把实际 Viewer 称作 Reviewer，现区分两种角色；拒绝结果进入 ACL 审计。广播函数本身仍是占位，不能据 await 修复宣称实时协作已完成。

Prompt 变为 `m3-openai-7`，旧云检查点须重新委托。视觉 Prompt 和端点命名空间缓存键保持不变。无新依赖、数据库迁移、线上 DDL、部署、SSH、提交或推送；原用户数据库未打开。测试生成的历史截图在最终验收后按本轮开始时的备份字节恢复。

当前仓库已包含作者跨项目设置/投影和 M5 HTTP 评论/提案/快照端点，本地云 13 项测试覆盖已有切片；旧文档中的“无 API 代码”是历史。生产部署、本项目 Postgres 权威、真实 Web 审稿和双端同步本轮未核验，不能沿用旧“绝无部署”或新“已全部上线”的断言。

## 剩余问题与后续顺序

1. 持久化/增量语义索引、廉价全图库观察与高能力策展分工尚未完成；当前每次重建有界平面文本向量，只覆盖已有合法缓存。历史 SQL 聚合成本仍随观察历史增长，单次系统模型调用不能强制打断；3 秒不是硬实时保证。其他系统显式回退，未完成原生验收。
2. 同语言检索、无相关性阈值；最近邻可能不相关，缓存事实本身可能有误。没有专业精度/召回、延迟或摄影效果结论，也没有语义偏好记忆检索。新增作者跨项目开关尚不能代替 Agent 检索接线和 Creator 身份隔离。
3. 完整多 Adapter、供应商特定授权和实际故障回退、模型质量持续评测、账单校准仍需完成。只出现配置/决策辅助源码不算授权与执行链路验收。
4. M3 的 >=30 个授权创作任务、分层/专家/竞品同题评测和摄影师项目门槛仍开；AI 模拟角色继续独立统计，不能计真人。
5. M4/M5 仍需生产身份与 Postgres、Workspace/Invite、受控上传/Promotion、真实 Web 两端旅程。现有云提案审批缺完整事务和正式操作应用，评论跨项目父引用/照片锚点未完整校验，WS/Presence/断线重连与快照恢复仍需实现及并发测试；本轮只修现有测试和 Viewer 权限，不扩大为云功能交付。
