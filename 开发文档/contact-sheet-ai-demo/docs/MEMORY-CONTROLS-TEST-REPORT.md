2. 人工保留前两张，各记录「留白」；第三张淘汰并记录「留白太多」。假设显示 2 条支持、1 条反例，并可展开原文及照片名称。
3. 确认假设；排除支持证据 #4 后支持降为 1，排除反例 #6 后反例移出，再分别恢复。移除假设后默认隐藏，勾选显示已移除项可恢复为未确认；停用与恢复检索正常。
4. 搜索「逆光」无匹配，搜索「留白」匹配。提交「只是这两张照片的特点，不是稳定偏好。」后假设保持已纠正/停止检索，移除再恢复仍保留纠正。

## 剩余问题与边界

1. 排除证据、移除假设是可恢复的学习控制，不是物理擦除。人工备注、审计记录、旧草案、工具协议、检查点及备份仍保留，界面与 PRIVACY.md 已明确。
2. 假设由关键词共同出现推断，支持/反例仍是规则分类；不做语义理解、稳定审美定论或向量检索。跨项目 opt-in 尚未实现。
3. 新的批量证据保留所有参与者；旧版已经丢失的参与者或当时说明不能凭现在的备注重建，原记录保持原样。
4. 真实模型/真实计价、签名公证、20 位真人 Beta、目标硬件的大图库性能与钥匙串写删仍未在本轮补验。

工程决策见 [ADR 0012](ADR/0012-m4-local-memory-controls.md)。KISS/DRY/SOLID：复用 SQLite、命令事务与任务状态机；把记忆控制、FTS5、证据列表拆为单一职责模块；无新增依赖。
