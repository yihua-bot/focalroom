# ADR 0014：记忆物理删除与观察缓存清空

日期：2026-10-15。兑现 PRIVACY 的删除承诺；范围见记忆控制既有边界（ADR 0012）。

- DeleteHypothesis/DeleteEvidence/PurgeObservationCache 三个记忆命令（migration 0010 墓碑表；同请求重放幂等由 request_id 回执保障；行不存在返回 NOT_FOUND）。
- 假设删除写表述墓碑：确定性物化引擎跳过同表述候选——物理删除不因剩余证据复活（AG-11 的物理版）。
- 证据删除同步解链：引用它的假设移除该证据 ID；引用清空的假设自动退役且不可确认。
- FTS5 检索索引按项目整体重建（可重建索引，原证据行删除后不留检索残留）。
- 清空观察缓存仅删本项目 photo_observations：云端已上传数据不受影响，再次视觉观察需重新授权并重新上传（缓存命中不再的语义如实呈现）。
- UI 全部经 window.confirm 明示「物理删除不可撤销」；PRIVACY 的「不是物理擦除」表述更新为已提供删除入口、备份/日志边界如实声明。
