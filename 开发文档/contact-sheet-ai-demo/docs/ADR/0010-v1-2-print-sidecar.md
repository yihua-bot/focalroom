# ADR 0010：v1.2 第一轮——印刷参考与元数据侧车

状态：已实现（2026-10-14）。范围见 [PLAN-V1.2](../PLAN-V1.2.md)。

印刷参考不引入 PDF 生成库：输出 A4 横版分页 HTML（@page 规则 + 封面 + 每页双图带裁切参考线），经系统「打印 → 存为 PDF」得到 PDF。理由：零新依赖、版式即代码可测、用户保留打印参数控制权；文档内明示「非最终色彩管理」。页跨图编辑（跨页拼版）涉及序列模型与撤销语义扩展，留待试用反馈后单独设计。

元数据侧车按行业 XMP 惯例为每照片一文件（`{序号}-{安全文件名}.json`）+ manifest（文件清单/序列/项目指纹）；导出为目录且只新建不覆盖，路径字段默认私密可 opt-in，与既有导出安全语义一致。文件名 sanitize 只保留字母数字/-/_并限长。
