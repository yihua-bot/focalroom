# ADR 0035：照片缓存事实的本地语义候选检索

后续更新：2026-10-17 [ADR0036](0036-m3-persistent-semantic-index.md) 已增加有界文件持久化/增量复用和清空联动。下文“不持久化”及相应剩余项保留为当时设计，以0036和其测试报告为当前状态。

日期：2026-10-17。接续 ADR 0033–0034；范围限 M3。保留已有关键词接口、云协议和作者记忆改动；无新依赖、schema migration、原图外发或生产操作。

## 问题与选择

缓存事实已有来源/范围/版本校验，但字面检索不能把“骑两轮车的人”与“男子骑自行车经过街道”作为候选关联。当前没有已配置的 embedding 服务；新增云端文本/图片供应商需要新的数据授权和费用处理，不能默默继承 DeepSeek 图片授权。

使用 macOS NaturalLanguage `NLEmbedding` 的本机句向量，在本机已具有相应模型时生成真实中文/英文文本向量，做平面余弦排序。本轮实测中文 revision 1 / 640 维、英文 revision 1 / 512 维。模型来源见 Apple 的 [句向量 API](https://developer.apple.com/documentation/naturallanguage/nlembedding/sentenceembedding%28for%3Arevision%3A%29) 和 [向量接口](https://developer.apple.com/documentation/naturallanguage/nlembedding)。这是 API/来源说明，不是摄影效果、跨语言能力或长期服务保证。

## 实现边界

1. **独立只读工具**：新增 `search_photos_semantic`，参数沿用 project_id/query/limit。原 `search_photos` 的字面匹配、评分筛选、顺序与无上传语义保留。两个工具共享最新缓存读取/校验函数，不维护第二套授权或来源规则。
2. **数据范围**：先做任务与工具 PolicyGate；仅读取项目/allowed_photo_ids、当前源 hash、模型和端点缓存命名空间符合要求的最新合法观察。云任务无模型绑定拒绝。每照片只将前两条非空、无 NUL、各不超过 400 字的 visible_facts 送入本机句向量；interpretation、原图、预览像素、路径、偏好证据不进入向量输入。元数据仍为关键词匹配。
3. **排序的含义**：关键词命中优先，其余按向量余弦相似度降序，稳定处理同分。没有相关性通过阈值，最近候选也可能完全不相关。每项保留 observation_id、观察模型/缓存版本、实际引用事实、不确定性与 human_preference_evidence=false；只在语义候选上附加对应文本的相似度，不混淆字面命中引用与向量文本。工具报告 native Provider、语言、revision、维数、实际生成/重新校验数量与质量 unmeasured。不能当作审美评分、内容置信度或已观察全图库。
4. **先计算、再核对**：读事务取得文本后结束；`spawn_blocking` 在写事务外运行本地向量，最多两个工作槽。每行固定最大 1024 float，最多 500 候选加一条查询。进入既有工具写事务后重新查询来源，以任务/完整调用指纹和观察 ID/模型/缓存版本/完整正文摘要匹配准备结果；修改、删除、范围或来源变化后旧分数不能复用。报告 revalidated/discarded_prepared 区分实际可使用的分数。
5. **时间与取消**：预处理纳入工具 duration 和原任务 elapsed；总时限不足则原有预算路径暂停。单批最多 3000ms，每条推断之间检查时间，单次系统模型调用不能被强制中断。槽位随阻塞工作持有，即便外层 future 取消也不提前释放造成无界排队。取消后写事务重查任务状态，不产生迟到回执或草案；重复 call_id 在准备阶段就跳过，仍由唯一 CommandHandler 的持久回执重放。
6. **失败明确**：模型不可用、非支持语言、超过语义查询/时间限制或工作槽忙时，报告状态并保留合法关键词结果。没有任何可重新核对的向量时 mode=local_keyword_fallback。查询最长 400 字参与语义，工具原有 4000 字契约继续用于字面路径。同一批只用一套语言模型，非同语言描述会跳过；不宣称跨语言搜索。
7. **临时派生数据**：每次调用重建有界平面向量；返回排序后丢弃向量，不增加文件/SQLite 向量表或长期缓存。因此删除/清空观察后新检索不再取得旧向量，历史工具回执仍按既有审计规则保留。没有承诺擦除历史/备份或系统内存的全部字节。
8. **原生接入**：构建时用已有 Xcode clang 编译小型 Objective-C 桥，Rust FFI 校验内存边界、有限数值、维数与成功掩码，框架异常不回显输入。NaturalLanguage 弱链接并作 macOS 11 可用性检查；发布包不需要运行 Swift 编译器或下载 sidecar。非 macOS 保留明确的关键词回退，其他系统尚未原生验收。

## 兼容与原则

云 Prompt 升至 m3-openai-7，旧云检查点须重新委托；视觉 Prompt/缓存键不变，不修改历史记录。Mock 旧关键词工具照旧，可继续重放已有回执。Native 文本向量是独立本地实现，不给任意 Responses 型号增加 embedding 能力，也不提供跨供应商 fallback。

单一职责：语义模块只算向量/排序，缓存模块负责来源和重新校验，CommandHandler 继续控制工具回执/预算/状态。DRY：共享缓存规则。KISS/YAGNI：先交付实际可运行的本地文本语义检索，不引入远程服务、ANN 数据库或自动图库全扫描。

## 尚未解决

没有完成持久化/增量向量索引、全图库廉价观察、跨语言检索、语义偏好记忆检索、低价索引/高能力策展模型分工。Apple revision 也不能当作固定权重文件摘要；专业召回/精度、延迟与跨系统模型可用性需要正式评测。合成文本的本地真实向量测试不计 LUMIX 质量任务或真人评审。M3 整体仍 partial。
