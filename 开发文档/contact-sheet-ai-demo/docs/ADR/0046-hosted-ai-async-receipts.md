# ADR 0046 · 托管图像请求的异步回执

日期：2026-10-23。状态：本地实现与隔离验证；本聊天未部署、迁移生产库或调用真实模型。

## 原因

同步图片分析可能超过 HTTP 链路的等待时间。外部增量已提供 0021 结果列和异步路由草案，但草案缺少原账本必填列、使用表约束之外的状态，且绕开图像授权、计量验证和事务结算。保留已经报告应用到生产的 0021 文件字节，不改旧迁移或放宽 0015 的约束。

## 决策

新增提交/轮询入口，继续由现有 NestJS `All → handle → route` 分发；控制器只委托 HostedAiService，不另开绕过权限的模型代理。

- POST `/api/v2/ai/deepseek-flash-v1/responses/async`，使用客户端 UUID 的 `x-focalroom-request-id`。PENDING 返回 202，已结束回执返回 200。
- GET 同一路径加 `/{requestId}`，只允许登录账户读取自己的回执。服务端返回的 pollUrl 是固定相对路径；客户端自行构造可信地址，不跟随模型/响应指定的任意地址。
- 复用同步接口的会话、邮箱、CSRF、策略、strict 输入、JPEG 重编码/去元数据、图片同意、额度和限流。两条路径共享 prepare/reserve/execute。
- 状态继续使用 PENDING / COMPLETED / REJECTED / UNKNOWN。PENDING 覆盖已预留及执行中，不能写入 RUNNING/FAILED。
- 每账户行锁保护预留；仅首次插入者执行模型。异步相同 UUID、相同正文读取旧回执，不再预留或执行；同编号不同内容拒绝。同步旧接口仍拒绝重放。
- 结果、实耗和额度同事务结算。只有确定的供应商拒绝释放预留；超时、网络错误、5xx、缺失或异常计量保留为 UNKNOWN，不能无条件退款。
- 进程中断的 PENDING 在超过上游 300 秒和额外 60 秒余量后，查询时投影为 UNKNOWN，保留额度。确切迟到回执可在尚未结算时原子结算；人工已结算的记录不会被覆盖。

## 结果保存与隐私

本 ADR 扩展 ADR0044 中“服务不保存响应正文”的旧同步边界。仅异步完成结果存入 0021 的 result_json，限现有上游响应大小；不持久化请求提示词、图片、账户 token 或供应商密钥。结果只向所属账户返回。

恢复结果的读取期限为完成后 24 小时；过期查询清除正文并返回 AI_RESULT_EXPIRED。服务启动及每小时尝试清除其他过期结果；停机或数据库故障会延后物理清理，备份仍可能保留旧副本。计量、摘要和审计记录保留，结果过期不退款、不重新调用。

## 客户端与恢复边界

仅托管图片请求改走异步；文字与直连供应商路径保留。提交一次，随后每两秒查询；单次提交 30 秒、单次查询 15 秒，整体轮询约 330 秒且仍受任务原有剩余时间限制。提交回执丢失时按已知编号查询，最多额外重试两次只读查询；不重发模型 POST。错误携带脱敏 requestId，不能自动新建付费重试。账户变更、会话撤销、错回执和 UNKNOWN 均停止。

这是持久回执与进程内后台执行，不是持久任务队列。进程被强杀不会恢复执行或重传照片；重启后只能读取已有结果或确认 UNKNOWN。客户端进程重启后的自动续接轮询 UI 尚未实现。长文字请求仍可能遇到同步等待问题。上线前必须复核生产 0021 的登记/摘要、真实传输和账户账本，不能由本地夹具推断生产已修复。

## 大小限制的证据边界

代码中的 Express AI JSON 上限和 Nginx 请求体上限均为 16MB。本地真实 HTTP 用超过 2.5MB 的有效 JPEG 输入验证解析通过；超过 16MB 被明确拒绝。这不验证生产 Nginx/Tunnel/网络的实际配置。

Cloudflare 官方公开的默认上传上限并非 1MB，且区级配置可调整。连接被关闭本身不能定位根因。依据：[Cloudflare 413](https://developers.cloudflare.com/support/troubleshooting/http-status-codes/4xx-client-error/error-413/)、[Cloudflare 524](https://developers.cloudflare.com/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/error-524/)，2026-10-23 查询。不得仅靠统一降为 512px 或增加超时宣称专业视觉链路已完成。
