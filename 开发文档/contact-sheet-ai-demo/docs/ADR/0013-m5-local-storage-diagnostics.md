# ADR 0013：M5 本地存储诊断

日期：2026-10-15。本轮只补齐 M5 的本地只读诊断，不增加迁移、清理入口、外部请求或跨项目记忆。

- 桌面命令与集成 harness 调用同一诊断模块，统一原来不一致的计数结构；数据库计数失败返回明确错误，不再伪装成 0。
- 固定应用数据目录，统计数据库主文件、WAL、SHM、平面图片缓存和迁移备份的逻辑文件大小；不递归遍历用户原图或导出目录，不返回路径、文件名、备注、项目名称、密钥、端点与模型回复。
- 文件统计使用后台工作线程；忽略缺失的可选 WAL/SHM 与尚未建立的缓存目录，不跟随符号链接。目录不可读、非普通文件、嵌套目录或扫描上限会标记不完整，界面显示已统计下界或暂不可用。
- 数据库计数在同一读事务中完成；文件体积是随后采集的即时观测，读取期间可能变化，不宣称原子快照、物理磁盘占用或可还原备份。
- 诊断对话框先展示可读统计与脱敏 JSON，用户主动复制；不自动发送、不写入项目状态。UI 与 IPC 各有单一职责模块，无新增依赖。
- 测试使用临时库和演示素材；原生验证沿用独立 Memory Review identifier（schema 未变），原用户应用不升级。
