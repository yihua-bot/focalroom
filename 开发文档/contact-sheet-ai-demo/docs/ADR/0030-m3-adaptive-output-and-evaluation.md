# ADR 0030：预算内单轮输出规划与可复核质量评测

日期：2026-10-16。范围：v2 M3；不增加数据库迁移、框架或依赖。

## 背景

真实开放任务会因每轮固定预留 8192 个输出 token 而在尚有剩余额度时暂停。不能通过扩大预算、自动结束现有草案或放宽可审阅条件解决。M3 质量门槛另外需要授权任务、完整失败分母和摄影师盲评，不能拿协议冒烟或模型自评替代。

## 决策

1. PolicyGate 在现有服务档位与任务总额度的较小值内规划本轮输出上限。先预留完整输入上界，再收紧输出；最少 128，最大不超过已委托的原始上限，不够则暂停。仅修改请求副本，持久化任务预算不变。
2. 每次 `model_attempt` 的现有 JSON 保存实际发送的 `maxOutputTokens` 和预留费用。结算读取该轮真实预留并按发送上限检查实际输出；未知完整计量仍保留预留，不能用可见文字退款。超过发送上限的结果在执行任何新工具前暂停。兼容旧记录时采用原任务上限，旧 Prompt 检查点需重新委托。
3. 系统提示最终为 `m3-openai-5`、视觉 `m3-vision-2`，说明单轮上限、JSON null 与单对象输出；格式错误继续拒绝。已确认的 DeepSeek 官方端点/Flash 使用带日期的峰时非缓存费率；未知端点/模型保留原 conservative coefficient。预留/结算从同一版本计算，视觉事务也检查服务档位有效上限。实际 token、估算和账单分别记录；没有分项的视觉总 token 用更高输出价估算，不声称服务商账单有绝对封顶。来源和日期见 `agent/pricing.rs` 与本轮报告，后续价格变化须更新并回归。
4. 真实任务验收的目标数按产品审阅页的 `keep` 候选计算。草案中额外 `undecided/reject` 仍需 ID 唯一、位置连续、真实作用域合法；不会因为附带待定项把两张有效候选误判为六张。候选过多/过少、暂停、零草案、过预算仍拒绝。
5. M3 评测放在独立 `tools/agent-eval`：严格 Zod 输入、预登记 attempt、失败保留、授权范围、状态/原图摘要、费用来源、阶段/版本、五维真人评分及事实抽查。纯评估函数和文件 CLI 分离，复用现有 Zod/Vitest/Playwright，不增加模型或云服务。
6. 盲评候选按随机种子匿名排列；原始运行信息和映射保留在私有文件。收集评分后用原 seed 与冻结输入摘要重算，改过任务/运行内容须另起批次。工具不证明权属、真人身份、登记时间或外部证据真实性。
7. 离线 HTML 使用本地文件选择器读已派生的预览，CSP 禁止网络，文本用 DOM textContent；仅生成匿名评语下载。未保存/导出的内容不持久化。此工具不承担 M4 云认证与项目权限。

## 权衡与验证

收紧输出可能使供应商返回 incomplete；依然按原有严格响应处理失败，不运行残缺工具。一次成功不代表稳定完成率或专业质量。测试覆盖预算不提升、发送上限/预留一致、越限轮零新工具、真实任务候选语义、缺授权/缺审计/重复任务、失败分母、匿名映射冻结、CLI 覆盖拒绝、真实 Chromium 评分/导出/零 HTTP 请求。

## 回退

代码回退会恢复保守的固定输出预留。未改 schema，现有 JSON 新字段可忽略；不得删账本或修改旧审计。任何在途未知请求继续保留费用与上传预留。评测输出均在新目录创建；回退不删除真人记录、私人映射或照片，也不改变原用户数据库。
