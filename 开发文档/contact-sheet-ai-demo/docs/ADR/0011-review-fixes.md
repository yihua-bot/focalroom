# ADR 0011：评审发现的六项链路修复

日期：2026-10-14。范围：M3/M4 与 v1.2 的评审缺口，不新增产品版本功能。

1. Provider 读取持久化工具结果中的 `callId`，保持调用与回执关联；结构化项目、预算和记忆数据进入请求，并明示为数据而非指令。主请求与视觉请求均设置输出 token 上限。
2. 前端 IPC 的图像预算与图像/费用用量接受非负数，图像预算范围与 Rust 保持 0–100。校验仍拒绝非法数据。
3. 导出格式映射由 Rust `export::destination` 统一：print 保存 HTML；sidecar 选择父文件夹并在其中新建唯一名称的目录。已有文件/目录不会被覆盖。
4. 模型请求先预留文本估算费用；视觉请求先经 PolicyGate、任务状态、工具/时长、图像和费用预算、consent 检查，然后持久化预留并外发。视觉账本复用现有 append-only `agent_steps`（`vision_reserved`/`vision_settled`），调用 ID 绑定完整指纹，不增加表或改历史 migration。成功响应结算费用并释放多余预留；超时/坏 JSON/中断保留预留。已保存结果可恢复回放，未知结果不自动重传。暂停/取消后到达的响应仍结算费用，不能改回执行状态。
5. 单次 consent 在 StartTask 事务中绑定 `task_id`，拒绝重复绑定；隐式回退仅允许 project 授权。旧版已消耗但未绑定的 task 授权不能重新绑定，需用户重新授权。前端不把 task 授权当项目常驻授权，禁止上传也落库为 deny。
6. 假设身份移除支持次数，旧版含次数的 statement 按相同稳定身份匹配。新增证据合并到同一假设，保留停用状态；已纠正或退役的同义历史记录不进入检索，包括旧版已经重复生成的记录。无需修改旧数据结构。

费用沿用工程估算规则（每图 1 美分、每千计量单位 1 美分）：文本使用 UTF-8 字节估算，视觉请求预留每图 4096 输入计量单位和输出上限。它不是模型服务商账单；实际模型/网关的价格、图像 token 计量与真实 E2E 尚待校准。供应商返回超出预留的用量时如实记账并暂停，不截断数字隐藏偏差；目前不宣称任意外部网关账单有绝对硬封顶。配额和图像用量包含结果未确认的请求预留，不能将断网视为“未上传”；需要重新委托时由人类明确发起。

验证默认离线：显式空 `BETWEEN_FRAMES_OPENAI_API_KEY` 禁止回退到用户钥匙串；集成 harness 固定使用此设置，视觉测试显式注入本地 HTTP Provider。`verify-all.sh --skip-keychain` 可跳过写删回环，其余检查不跳过。

KISS/DRY：复用检查点、事件账本、命令通道和导出器；不添加新的框架、依赖或 schema。职责分离：云端预留/结算放在 `agent/cloud.rs`，网络与事务分离。
