# ADR 0008：M5 Beta 工程准备

状态：工程部分已实现并验收（2026-10-14）；签名/公证与真实用户 Beta 属发布流程，未完成。测试证据见 [TEST-REPORT](../TEST-REPORT.md)。

API key 存储补齐规格 §12.1：macOS Keychain 经系统 `security` 命令读写（无新依赖），解析顺序为显式环境变量（开发）→ 钥匙串（用户存储）；GUI 提供「存入/移除钥匙串」。已知权衡：写入瞬间 key 出现于本机进程参数（单人桌面可接受，PRIVACY 如实说明）；非 macOS 平台返回未集成错误而非静默降级。

性能基线以可复现测试固化（`perf_baseline`，--ignored 手动运行）：Release 构建下 200 张 1200×900 JPEG 导入 2.9s（70 张/秒）、决策命令 p95 23.0ms、投影读取 3.4ms——均优于规格目标（导入 ≤120s、p95 <150ms）。Debug 数字（导入 121.5s、p95 172.7ms）同时保留供对照；规格性能目标以 Release 产物为准。

诊断命令 `get_diagnostics` 输出版本/计数/配置状态，明示不含照片内容、密钥、路径与备注文本；Beta 旅程 E2E 以真实后端串起 意图→导入→选片→委托→草案→局部采纳→假设纠正→导出→重启一致性 的完整剧本，对应 M5「真实项目闭环」验收精神的自动化底座。隐私说明独立成文（PRIVACY.md），如实声明 append-only 证据边界与未签名状态。
