# ADR 0004：M1 命令事务、可恢复历史与私密导出

状态：已实施并完成 M1 验收（2026-10-14），停止等待评审。范围见 [PLAN-V1-M1](../PLAN-V1-M1.md)，结果见 [测试报告](../TEST-REPORT.md)。

GUI request 不包含 actorType/source，可信 IPC 通道注入 human/gui_direct；恢复与补偿由后端标记 human_restore。未来工具通道只能使用后端绑定 scope，不能重用 GUI 通道冒充人工。M1 没有 Agent 通道或服务。

命令 ID/幂等键绑定项目、可信来源、预期 revision、因果 ID 与参数指纹；授权检查先于回放；同键不同请求拒绝，合法重试返回持久化原结果。前端收到早于本地快照的回执后重查当前投影，避免历史重放导致界面倒退。

编辑历史使用 before/after 可编辑状态与项目级线性栈；补偿生成新命令/决策事件，不删除历史。比较记录只逻辑撤回，版本不可变。新分支废弃 redo 可达性并保留记录；旧组撤销拒绝。导入/重链属于只读资源引用，不允许 Undo 删除照片或移动原图；项目新建和版本保存为审计操作，撤销栈针对人工编辑与归档/恢复。

版本保存正式序列及当时人工状态/评分/备注；恢复明确显示影响范围，保持未快照照片在项目中并设为待定，原图引用不恢复旧路径。版本恢复是可撤销的新编辑，不修改历史版本。

兼容升级保留已应用 migration 的 checksum；0003 只建立 M1 所需表/约束。已有数据库升级前以 VACUUM INTO 生成包含已提交 WAL 的备份并核验完整性，失败停止升级。此轮用户原应用和 M0 Review DB 保持不变，仅临时副本与独立 M1 Review 验收。

CSV 默认省略资源路径列；JSON 递归移除原图、预览、缩略图的已知路径字段，包括旧事件中的字段。显式迁移选项才附加资源引用。人工输入的备注/意图仍按原文导出，此机制不承诺清除用户主动输入的路径。本地命令回执可保留恢复所需状态，不作为默认导出/遥测。

GUI 的 expectedProjectRevision 必填：新项目为 0，其余为读取的实际 revision。causationId 允许 null 但不能缺省。14 类 GUI 命令由同一 JSON Schema 生成 Rust/TS；无参数命令也采用空结构体，确保 serde 拒绝额外字段。资源导入/重链仅由可信内部通道构造。审计持久化完整 canonical command_json 与补偿目标；别名表为合法重复请求保留 alternate command ID/幂等键，阻止之后换参数重用。

旧项目的人工事件完整保留，以升级时状态作为新的撤销起点，不伪造旧操作的 before/after。Undo/Redo 仅适用于新命令形成的编辑栈。序列版本保存人工状态、评分、已保存备注与顺序；未保存 UI 草稿不在其中。审计和版本采用状态快照，M1 优先可验证的事务恢复，后续需以真实图库量化存储增长。

原生验收确认 Tauri 事件名只接受字母数字、- / : _，点号会被拒绝。逻辑名称保留 project.changed / photos.imported，传输名称映射为 project:changed / photos:imported；映射从 contracts/app-events.json 同步生成 Rust/TS 常量。浏览器集成的系统/事件传输替身不能代表原生监听已通过，必须用最终原生构建补验。
