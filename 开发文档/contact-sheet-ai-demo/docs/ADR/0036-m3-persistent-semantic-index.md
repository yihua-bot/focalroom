# ADR 0036：本地句向量的持久化增量复用

日期：2026-10-17。接续 ADR 0035 的真实本地句向量工具，范围为 M3。项目 SQLite schema、既有迁移、视觉缓存命名空间、云 Prompt m3-openai-7 均不变；没有新增依赖或外部服务。

## 选择

在应用现有 cache 目录中保存可重建的 JSON 向量索引，按数据库路径与项目摘要隔离文件。文件包含版本、单一语言/revision/维数的 Apple 模型描述、观察完整内容/来源/源 hash 的摘要、照片标识摘要及 f32 向量；不保存事实原文、文件路径、查询、查询向量或检索分数。向量仍是私密派生信息，不能当作匿名化或加密。

每项目最多500条、8MiB；读入前检查文件类型/大小，解析后严格校验 schema、SHA-256 校验和、版本、语言、revision、维数、唯一键、向量长度与有限/非零数值。缺失、损坏、目录/文件链接或不可读时明确报告，使用当前有效事实重新计算，检索不依赖文件作为授权依据。Unix 新文件为0600；同目录独占临时文件写完、sync后原子替换。已知链接拒绝及打开后元数据复核不是对恶意本机用户任意并发替换祖先路径的完整安全证明。

## 增量与来源

预处理沿用任务 scope、当前源 hash、最新合法观察及实际端点/模型绑定校验，仍最多取500张的前两条可观察事实。文件读入和原生推断都在最多两个阻塞工作槽中，包含在原任务耗时内。查询每次重新生成向量；C桥加载当前真实系统模型后，只有语言、revision和维数都一致的候选向量才能复用。新增、修改、来源变化的文档按新摘要重新生成，其他候选继续复用。报告 cache_hits/generated 是文档数量，不包括每次查询的推断，也不作为召回质量指标。

计算后仍由 CommandHandler 获取数据库写锁、重新验证任务/调用/范围/完整观察摘要。只把本次通过重验的候选向量发布到文件；按照片摘要替换旧条目，保留其他候选，超限时淘汰最早访问条目。发布前重新读文件合并，避免同数据库任务互相覆盖。结果中的 index_entries 仅为本次范围内发布数，不暴露项目其他范围的缓存条目数量。写失败报告 unavailable，当前合法检索仍可返回，不伪装为持久化成功。

这是有界平面向量索引与增量推断，文件更新仍整文件重写；不是 ANN、全图库后台索引或廉价视觉观察服务。单文件只保留最近使用的一套语言模型；切换语言/模型会重建该项目缓存，不承诺跨语言复用。Apple revision不是模型权重摘要，系统模型长期一致性仍有限制。

## 清空与事务

已有“清空视觉观察缓存”命令在同一个数据库写锁内先把派生文件原子替换为空索引，再删除观察并提交原有记忆命令回执；文件清空失败则返回CACHE_WRITE并回滚，不宣称观察已清空。缓存先清空而后续SQL失败只损失可重建数据，不会恢复旧向量。取消、观察变更或清空后，旧预取无法通过重验并重新发布。重放成功清空回执不会重复清除后续合法的新缓存。

缓存文件不是SQLite事务的一部分：工具回执提交失败时，文件可能已包含仍有效的派生向量；这不改变正式状态、证据或权限。普通观察删除/修改后，旧条目不能检索；未再次访问的旧条目可能留至淘汰或主动清空。进程崩溃可能留下临时文件，备份、历史回执、文件系统旧块及内存不在安全擦除承诺内。目前没有全局项目数量/磁盘配额或临时残留清理功能；诊断会把普通缓存文件计入占用。

## 验证与原则

实际中文640维/英文512维模型验证冷启动、连接重开、单张更新、版本/语言/维数错配、scope、清空以及原图/正式状态保护；合成事实不计摄影质量或真人。系统语言识别会误判（本机把重复的英文句子识为nl），该条明确跳过并标记limited，不能用工程通过宣称完整召回。

职责分离：semantic_index仅处理有界派生文件；semantic计算/复用向量；photo_search控制来源和发布；CommandHandler仍是任务与人工清空的唯一状态入口。复用现有缓存目录和工具契约，不为派生数据引入新服务、迁移或索引数据库。完整结果见 [本轮验收](../V2-M3-PERSISTENT-INDEX-TEST-REPORT.md)。
