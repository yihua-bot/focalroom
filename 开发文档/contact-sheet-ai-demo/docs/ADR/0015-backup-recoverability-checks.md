# ADR 0015：备份可恢复性巡检

日期：2026-10-15。把 M5 诊断中「备份只有计数」升级为「可恢复性状态」。

- 诊断收集时对最近 5 份升级前备份（新→旧）做只读 quick_check：ok（可恢复）/ corrupt（完整性异常）/ unreadable（SQLITE_NOTADB 26，非数据库文件）；文件名与大小随附，不含路径。
- 巡检在文件统计的后台任务之后于异步上下文执行，只读连接、逐份串行，不阻塞启动与编辑。
- 语义边界如实：巡检是快速校验，不等于全量恢复演练；异常备份保留原处供人工评估。
- 应用内不提供自动恢复替换入口：恢复意味着回到升级前快照、失去其后全部编辑，属重大数据决策；且运行中替换打开中的 SQLite 需要退出期协议。待产品确认真实需求后另行设计（本 ADR 记录不做的原因）。
- 测试覆盖三态（健康 VACUUM INTO 产物 / 截断 / 非 SQLite 字节）与名称脱敏。
