# ADR 0048：iPhone 私有同步与旧权威状态兼容

日期：2026-10-28。状态：开发验证中，未应用到任何既有或生产数据库。

旧 `fr_projects.state` 的 STAGING/SHARED/ABORTED 表示迁移与云端正式写入是否生效，不足以表达私人同步与协作共享。保留其字节与旧客户端行为，新增 `fr_project_sync` 表达 SYNC_ENROLLING → PRIVATE_SYNCED ↔ SHARED，失败可记 ENROLL_FAILED。缺少模式记录的旧项目继续按既有共享规则，不自动收紧或扩大权限。

新 iPhone 经独立 `/private-promotions` 入口创建迁移：源清单仍不可变、上传原有派生预览、完成后云端是唯一权威；本机记录继续冻结。PRIVATE_SYNCED 必须在服务端 principal 和列表层拒绝非所有者（包括工作区管理员），不可只改客户端标签。共享/收回由项目所有者显式操作，模式版本乐观锁与不可变命令回执保证重试安全。

收回为私有时，同事务撤销项目 grant、未接受邀请和任务授权；旧邀请不得重新授予访问。所有端点与媒体/实时通道继续复用 principal 校验。共享模式不自动恢复已撤销 grant，需重新邀请。模式事件进入现有事件流，不伪造照片/序列正式版本。

0031 只在新建、隔离 PostgreSQL 测试库验证。既有 0001–0030 不修改。升级生产或既有用户库需单独核对备份与迁移授权；旧程序因未知迁移拒启，禁止盲回滚。最小权限回归必须覆盖新增表。新增模式不代表已完成 Mac/iPhone 同时移动与真实设备验收。
