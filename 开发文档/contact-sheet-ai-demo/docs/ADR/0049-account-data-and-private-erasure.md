# ADR 0049：账号导出、关闭与私有作品正文擦除

日期：2026-10-28。状态：本地开发与隔离验证，未在既有或生产库执行。

账号导出采用身份隔离的一致性读取，只选公开业务列，不导出密码、会话、设备密钥或供应商标识。超过条数/字节界限时报错，不静默交付残缺资料；大账号需另行分批取回机制。

账号关闭须有效会话、当前密码、匹配邮箱和明确理解保留范围；有进行中 AI 任务或有效订阅时先处理，不能伪造取消或退款。关闭标记与会话撤销、资料匿名化、私有项目终止和内容清除在同一事务提交。旧会话/并发登录不得复活原账号；用原邮箱重新注册会得到新的身份，不能取回旧项目。本机原片保留供离线取回。

对本人私有且无其他可访问主体的项目，移除当前业务内容、预览与原始历史正文。共享协作作品继续服务已有协作者，保留匿名身份与作品历史；财务、计量、ACL 和最小删除审计保留。此行为在删除前清楚显示，不声称抹除共享协作者副本或离线备份，也不代替发行前的数据政策复核。

0001 的历史触发器禁止任何审计行更新。0033 提供限定例外：只有项目已经 ABORTED、所有者已关闭、且已追加删除审计时，才允许将 snapshot/envelope/detail 换成固定擦除值；所有身份、时间、命令号、回执、摘要等其余列必须逐字不变，所有 DELETE 继续禁止。普通编辑、未关闭身份、任意替换正文均拒绝。旧迁移字节不改。不是关闭触发器，也不是给应用 DDL 权限。

对象介质删除以持久队列重试。上传和清理用相同对象键锁，清理时重新核对所有预览/渲染引用；仍被其他项目引用的内容不物理删除。介质故障不回退已经关闭的账号，不将账号关闭回执当作所有介质清理完成证明。无对象删除能力的自定义存储必须配置清理适配器，队列不丢弃。

0031–0033 仅使用新建临时 PostgreSQL 验证。对既有库/生产应用仍须单独确认备份、迁移及发行授权。真实商店、备份保留周期、真人数据权利验收仍独立记录。
