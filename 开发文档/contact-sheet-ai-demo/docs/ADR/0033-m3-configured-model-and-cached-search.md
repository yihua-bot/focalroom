# ADR 0033：实际模型身份、恢复绑定和缓存事实检索

日期：2026-10-16。基线 `9976b16`，保留已有 M4 修复与 AI 模拟评审增量。范围限 M3 工程切片，无新依赖、schema migration、云服务部署或真实照片外发。按已有 DeepSeek 授权精确执行一次纯文件名真实回归，图片发送为 0。

## 问题

路由目录写死 gpt-4o-mini 与 professional，检查点从当时环境变量推断 modelId，注入实例和配置变化时记录可能失真。任务仅绑定 openai 适配器名，不能识别同协议下恢复时更换端点/模型。缓存键也缺少端点区分。search_photos 契约称可检索视觉描述，实际只查文件名/备注。

## 决策

1. **实例配置为权威**：运行时与上传前路由传入已实例化适配器的实际 model_id。AiConfig 返回实例的端点和密钥尾号；只有当前解析的密钥与实例一致时才声称 env/keychain 来源。未实测质量标为 unmeasured，驻留为 unknown；不据域名猜测区域。单独配置 allowed_residencies 也要执行区域门槛，unknown 不能满足受限部署。去掉未实现的 embedding_or_multimodal 能力；协议工具/视觉能力仍是适配器声明，不代表该模型已有专业质量、能力/可用性实测。
2. **不自动切换 provider**：实际执行仅选择任务绑定的适配器，配置缺失就拒绝。保留默认目录作为纯规则示例并明确 example/unmeasured，实际运行不从该示例读取模型名。默认优先级是部署配置，不再冒充质量/延迟排名；2 美分路由估算门槛沿用保守基线，实际请求仍执行已有分项预算与费率预留，非账单。
3. **首次执行绑定身份**：复用 append-only agent_steps，写一次 model_binding（providerId/modelId/endpointSha256）。端点标准化只 trim 和去末尾斜杠；凭证不入指纹，允许同配置轮换 key。每个云端循环在待执行工具/视觉回放之前校验，恢复时不同端点或模型拒绝；同一身份不反复落绑定记录。检查点和上下文记录实际模型，检查点身份必须和账本一致，不再回读环境推断。
4. **旧任务安全退出**：已有执行历史却无绑定，或 Prompt/检查点不匹配，要求重新委托，不补猜身份。允许 queued→failed，使初始化恢复失败释放项目执行名额，避免调度一直重试 queued。新的 Prompt 为 m3-openai-6；旧记录保留，不能用旧任务原地续跑来回避新语义。
5. **缓存按端点隔离**：复用既有 model_id，prompt_version 写为 m3-vision-2@endpointSha256。读取还限定 photo_id、当前记录源 hash、模型、工具种类；响应与缓存继续严格 schema/ID 校验。旧未证明端点的缓存不回填、不删除，在新命名空间视为未命中；仍需 consent/预算才可重新观察。
6. **分层检索第一切片**：文件名/人工备注/rating:4 保留；增加只读缓存 visible_facts 的 Unicode 字面子串匹配，返回 observation_id、模型、缓存版本、工具种类和不确定性。interpretation 不检索，不执行其中指令，不把模型观察写成 preference_evidence。无像素读取、无新增上传；未命中不等于图片没有该内容，缓存描述仍可能有错。
7. **边界与资源**：项目、任务 scope、源 hash 和当前版本先筛选，云任务还限定绑定的模型/端点；离线 Mock 只能读取本项目 scope 内现有描述。每照片取最新适用记录，无效最新记录不回退为有效命中。最多 500 照片/批、64KiB 每缓存 JSON、每命中至多两个 ≤1000 字事实；返回扫描覆盖范围。历史聚合只处理 ID 后才取有界最新 JSON，不宣称历史总量无关的查询时延；无新索引 migration，也非 embedding/语义向量检索。

## 验证与限制

用临时 SQLite、生成 PNG/JPEG 和回环 HTTP 注入测试，不发真实图片。验证数据库关闭/重开、待执行视觉调用前拒绝更换配置、key 轮换、端点缓存隔离、绑定后的云检索过滤、500 scope/501 图项目、Unicode 事实匹配、来源引用、损坏/超大/旧版本/旧源 hash/跨项目排除、正式快照及源 SHA 不变。额外真实 DeepSeek 文件名任务进入 review_ready，3 轮/4 工具/13,792 实际 token、3 美分估算，实际模型和检查点绑定核对通过；0 图片，不证明摄影质量。全量结果见 [本轮报告](../V2-M3-ROUTING-SEARCH-TEST-REPORT.md)。

身份在首次执行时绑定，不能代替项目创建时对具体供应商的授权证明；现有 consent 仍以适配器和任务为作用域，后续多供应商授权/切换需独立设计。模型别名也不等于冻结权重版本。没有以模拟评审或协议能力证明真实路由质量、多 Adapter/fallback、摄影师偏好、账单准确或 M3 整体通过。

## 回滚

原表和旧记录保留；只新增任务步骤和缓存 JSON/字符串命名空间。已有任务遇不兼容需新建委托，不清库、不重写旧缓存/历史。正式作品仍仅经人工 CommandHandler 命令写入；不把新绑定/检索数据作为人工证据。
