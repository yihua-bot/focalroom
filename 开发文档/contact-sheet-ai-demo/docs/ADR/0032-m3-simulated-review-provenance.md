# ADR 0032：AI 模拟评审显式标记，独立汇总并保持原始材料冻结

日期：2026-10-16。用户已明确允许“模拟真人”以继续开发。本决策支持模拟作者/编辑的产品演练，避免将模拟身份误计为真人或摄影师的审美记忆。

## 问题

原评测器只按 reviewerId 判断作者与其他评审者。若 AI 写两个人物 ID，工具无法区分来源，可能满足真人门槛并把模拟分数混入摄影质量均值。应用中的 preference_evidence 已只从人工命令取证，本轮继续保护这一边界。

## 决策

- 评语增加 reviewerKind（human / simulated_ai / unverified）和 reviewerModel。模拟须填实际模型或会话名，真人 model 必须 null；精确版本未知时不能虚构版本号。
- 页面要求显式来源，AI 模式显示固定说明。一个 reviewerId 在一个批次内的来源/模型不可变。CLI 对矛盾身份报错并排除该身份全部质量分数；旧来源缺失记录归为 unverified，不默认视为 human。
- 既有顶层分数、每运行分数、事实错误率仅统计来源明确的真人。模拟评分集中于 simulation，并设 isHumanQualityEvidence=false；未核实/冲突来源不计两类有效评分。只有实际真人记录可满足作者与独立评审门槛。
- AI 角色不等于额外真人、额外摄影任务或独立模型；不生成假的人类/竞品运行，不更改执行完成率、费用/失败分母或来源素材。分数是主观演练意见，不是审美批准。
- 导出 JSON 的每条记录带来源；纯模拟下载使用 simulated-ai-reviews.json，混合来源使用 mixed-source-reviews.json。CLI 新增可重复 --reviews，直接合并导出数据、复核原 key 和冻结摘要；不覆写旧批次/旧分数。
- publicPack 和评语绑定同一 packetId，由原种子及冻结输入摘要生成 HMAC。否则不同批次共享 case-1/candidate-1 别名，评语可能误导入。缺失或异批次标识直接拒绝，不计任何分数；该标识不等于真人身份验证或签名。
- 保持 bf-m3-eval-1，来源字段只影响 reviews，现有无评分批次及 key 不变。旧缺来源评语从质量统计移出是明确的兼容变化，而非静默迁移为真人。
- 旧 publicPack 无 packetId 时，保留原文件并用原 input/key 重新生成页面；旧评语缺批次先拒绝。不能静默为旧导出补写当前批次 ID。
- 工具只输出文件，不调用模型、不上传照片、不执行正式命令，也不写入审美记忆。真人身份仍需外部确认，软件字段不能防止组织者故意伪造。

## 本轮演练

用户已授权的 LUMIX 原始 1 任务/2 attempts 保留。当前 Codex 会话看 8 图总览及第 1/4/5/7 张 1400px 预览，模拟作者和编辑各一次，共 2 AI 评语、0 真人；同一会话不能称作独立盲评。重复核对四个宽泛事实不是八个独立样本。建议只存于仓库外演练材料，不自动采纳，不把反馈作为第三次人工偏好学习证据。

不修改旧评审页、私人映射、源照片或派生预览。新包使用新目录，恢复原无评分文件即可隔离演练。本轮不新增库迁移、依赖、云服务或模型请求；M3 真实质量/费用/路由门槛仍需后续推进，模拟不用于宣称 M3 通过。
