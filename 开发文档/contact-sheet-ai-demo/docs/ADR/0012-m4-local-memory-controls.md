# ADR 0012：M4 本地记忆控制、反例和关键词检索

日期：2026-10-15。补齐本地 M4 控制闭环；跨项目仍关闭，真实模型不在本轮调用。

- 证据原记录保持审计用途；用户可排除/恢复证据参与学习。假设可确认、移除及恢复。移除是可恢复的逻辑移除，不宣称擦除日志、检查点或备份。
- 新增 0009 migration 保存证据排除状态、带指纹的人工记忆命令回执，以及项目内 FTS5 索引。旧迁移不变，任何旧库升级前均进行含 WAL 的备份与完整性校验。本轮只在临时数据库和新独立评审 identifier 验收，不升级用户原库。
- 所有记忆控制经 CommandHandler；命令幂等且校验项目归属。它们不修改正式照片、序列、revision 或 Undo 栈。
- 已生效的记忆控制会暂停本项目执行中的 Agent。任务保存记忆 revision；旧任务恢复/答复被拒绝，需要明确重新委托，避免旧工具历史继续引用已排除记忆。历史草案保留供人类审核。
- 关键词材料来自当时保存的人工说明，不再用现在的备注倒填旧保留行为。新淘汰证据保存当时说明，作为关键词反例。批量决定记录为一次因果操作，不增加独立支持次数。
- 假设支持与反例按当前未排除证据重算，纠正/移除不自动复活。FTS5 使用中文二元词和常规词语，提供关键词相关性排序；属于可解释的文本检索，不声称语义理解。
- UI 明示审计保留边界，展示证据原文与反例，支持排除/恢复和假设控制。每次操作刷新记忆与任务状态。

KISS/DRY：复用现有 SQLite、命令事务、Agent 状态机与 Memory Studio，不引入模型、向量库或新框架。
