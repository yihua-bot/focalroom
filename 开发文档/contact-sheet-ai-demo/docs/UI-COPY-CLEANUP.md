# FocalRoom 界面文案清理

日期：2026-10-18

按用户要求，清理桌面工作台与 Web 共享评片中的开发自述、重复解释和宣传式措辞。

## 调整

- 项目、工作台、照片检查器、记忆、提案和登录页面移除重复说明卡与标语。
- “保存我的判断”改为“保存备注”，“摄影编辑 Agent”改为“编辑建议”。移除界面上的“v2 审批”“写入权威”等工程用语。
- 快速开始保留项目描述、照片数量、选片目标和创建操作，移除“我会帮你设置好一切”等自述。
- 模型设置、预算、用量、执行步骤及导出格式说明按需展开。失败、暂停和版本变化的原因仍直接显示。
- 任务状态和草案审阅移除写死的 Mock 标签；演示模式仍明确标记“不分析照片”。浏览器示例保留刷新重置提示。
- 保留图像上传的接收方、型号、配额、费用与撤回方式，以及迁移、只读、删除和覆盖操作的实际后果。
- 中英日韩对应词条同步修改，桌面与 Web 的四份语言包逐一核对一致。
- 弹窗说明改为可选；无说明时不渲染空段落，也不引用不存在的无障碍描述。

截图及最终测试日志位于 [evidence/ui-copy-cleanup](evidence/ui-copy-cleanup/)。现有 E2E 的文案选择器已同步，本轮未运行 Playwright E2E 或原生 Rust 回归。浏览器使用本地演练账号和生成的 8 张预览，未上传用户照片、调用模型或发送邮件。

## 范围

本轮仅调整前端呈现，不改变授权、审批和存储规则。没有部署线上，也没有重新制作 Tauri 安装包；M0–M5 阶段状态不因此改变。没有执行 git commit/push。期间其他写入产生的 `fa0d2b7` 已包含部分先行文案编辑，验收以最终工作树为准，未回退外部改动。
