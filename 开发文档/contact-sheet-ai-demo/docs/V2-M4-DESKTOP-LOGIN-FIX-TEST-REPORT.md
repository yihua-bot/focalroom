# M4 桌面浏览器登录与账户展示修复验收

日期：2026-10-19。原始评审基线 `20a90ec`；中途外部提交 `98c4fcb`、`f11c2f0`、`49fcc65` 纳入了本聊天正在进行的修改。用户确认暂停其他 AI 写入后，本聊天继续统一修复。没有执行 git commit、push、生产部署或生产迁移。不要把外部提交的计数或“工作树干净”当成本轮测试结论。

## 结论与改动

原评审指出的发起 URL、CSRF 误作凭据、插件未初始化、事件载荷不匹配、缺少会话保存、已有浏览器会话绕过桌面授权以及共享仍需密码的问题，已接通并补测试。账户资料链路也已补齐：数据库头像、会话返回、原生模型、GUI 解析、双端头像/首字占位、昵称/邮箱/退出及样式。

1. **协议**：原生 state/verifier 各由 CSPRNG 生成32字节；15分钟事务，S256 PKCE；网页明确确认后回传60秒单次授权码。深链只有 code/state，不包含 CSRF、会话 token 或 verifier。API 同事务检查源会话、授权码、PKCE并创建独立24小时桌面会话；并发只成功一次，撤销/兑换保持一致锁顺序。
2. **原生运行时**：初始化 deep-link 插件；处理 URL 列表事件与冷启动 get_current，对重复投递去重。严格校验 callback 协议、路径、字段、过期和 state。浏览器失败取消待办；取消后拒绝迟到回传。待办和会话通过 macOS Security API 写入独立 Keychain 服务，不进入 SQLite、localStorage、argv 或 GUI。
3. **界面与共享**：侧栏及共享窗口显示账户；命令完成和原生回调通知所有订阅者，退出/取消也主动刷新。清理订阅和迟到读取，不吞掉浏览器失败。共享只接收项目/地址/授权等参数，由 Rust 取得与来源绑定的凭据，移除邮箱密码。断网不允许上传，仍可本机退出并明确说明远端撤销结果。
4. **头像**：登记已有0014迁移，补认证、OTP、Google及桌面兑换 SELECT/RETURNING，头像立即返回且刷新可恢复。Tauri Zod 保留头像。双端复用 AccountAvatar；缺失、来源不允许或图片失败均用昵称首字，空昵称回退邮箱。Web顶部同时显示邮箱和退出，退出文案四语。Tauri/Nginx图片策略只增加指定 Google 图片来源，不开放任意 HTTPS。
5. **本地头像缓存**：合并已有缓存实现，改用账户/URL摘要文件名，拒绝非受支持的Google HTTPS地址；读取、下载及解码有界，支持PNG/JPEG/WebP，最多1MiB、1024×1024和16MiB解码分配，私有临时文件原子发布。GUI仅对桌面明确允许已验证位图data URL，Web不接受data/SVG头像。头像缓存不参与登录身份判定。
6. **Google边界**：本地协议夹具验证 audience、email_verified、自报资料拒绝、头像持久化及OTP复用。前端Google入口默认关闭；没有使用真实Google账号/Client ID完成授权。真实OAuth、生产CSP脚本/弹窗策略仍需单独验收，不能宣称Google已在线可用。

## 保留的失败与修正

- 早期新TypeScript参数属性在Node strip-only模式失败，改为显式字段；setup的AppError转换和新测试字面量类型也补齐。
- 接线过程中Lint发现effect状态更新及错误cause、类型目标ES2020不支持Error第二参数，分别修为异步外部读取/派生地址与显式cause属性。
- 头像新增邮箱展示后原有单元素断言失效，改为验证双处展示；PG新测试曾用全库用户数与并行套件竞争，改为验证本测试身份范围。
- 并行构建/回归出现rustdoc找不到Tauri依赖，后改为同目标目录顺序验证，最终doc-test通过。
- 外部缓存增量导致Clippy六项失败，并有下载无上界、清空probe头像导致无法下载、缓存data被前端拒绝的问题；用户暂停其他写入后合并并有界化，保留失败日志，不以此前通过覆盖。
- 原生选择器早期路径输入没有完成实际导入，保留失败；最终包通过系统路径建议定位目录后明确点击Open，实际新增2/2且0失败，再完成会话共享，不以早期0图冒充通过。
- Quark存在重复bundle id/读取超时；后来确认系统实际打开的是Chrome并完成协议验收，没有修改默认浏览器。

## 上线与剩余边界

本轮仅本地。上线需审阅并部署匹配的API/Web及0013、0014迁移，再发布对应正式桌面包。旧API不支持新握手；不能只换桌面二进制。生产必须沿用既有固定镜像覆盖方式、迁移角色和备份流程，不单用旧base重建，不down/prune。此前批准的固定修复镜像不等于本轮版本发布批准。

Google真实授权及邮件真实投递没有完成。macOS原生链路有测试，Windows/Linux当前明确不支持此登录实现。离线退出仅清本机，远端会话按撤销结果或24小时到期处理。M3真人质量门槛、M5真人双人项目及全部生产/签名验收不由本次登录修复自动关闭。没有依据“15/18”宣称M0–M5全部完成。
