## §15.1 Definition of Done

- cargo test / clippy / typecheck / npm test / E2E：`scripts/verify-all.sh` 全绿（45 Rust、28 单测、16+3 E2E、0 警告）
- 「不 mock 掉 PolicyGate 假通过」：agent_vision 走真实 Gate 与真实 SQLite ✓
- 新命令契约/事务/GUI 集成/错误处理：command_history 10 项 ✓
- 新 Agent 工具 schema/policy/鉴权/trace/幂等：契约校验（M1+Agent）+ agent_runtime ✓
- Prompt 版本记录：prompt_version 常量入 checkpoint/步骤，恢复校验一致 ✓
- 发布产物隐私说明：PRIVACY.md + 应用内引用 ✓

## §11.1 错误码集合核对

9 个规定错误码中 8 个在用（NOT_FOUND/PERMISSION_DENIED/VALIDATION_ERROR/REVISION_CONFLICT/BUDGET_EXCEEDED/MODEL_UNAVAILABLE/CANCELLED/RESOURCE_MISSING）。**CONSENT_REQUIRED 未启用**——记录为设计决定：无授权时视觉工具走「降级+结果明示」（mock_metadata_only），符合 P0-6「默认不打扰」与 P0-1「拒绝后仍可用」；UI 层在视觉预算开启且无授权时先弹授权卡引导。不视为缺陷；若产品要求「阻断并要求授权」再启用该码。
