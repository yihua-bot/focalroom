# v1.1 实施计划（第一轮）

依据主规格 §17：个人摄影项目模板、对照工作台更丰富的版式、项目标签与版本对比。本轮交付其中两项（版本对比、项目模板）；项目标签涉及 schema 迁移留下一轮，版式增强待设计输入。

1. 版本对比：版本快照已含序列与人工状态，纯前端实现——版本对话框支持「A vs B / 当前」对比，diff 呈现新增、移除、移位（from→to）与状态/评分/备注变化；恢复预览保留既有「版本 vs 当前」语义不变。
2. 项目模板：新建对话框提供模板快选（空白/家庭摄影书/街头纪实/旅行编辑/作品集初选），仅预填标题建议与创作意图示例文案；不写库、不新增后端，编辑既有项目时不出现。
3. 测试：两个组件的行为测试；全量回归 verify-all。

KISS：模板为静态常量；对比为纯计算无新 IPC。ADR 0009 记录「v1.1 功能在无迁移前提下先行」的决定。
