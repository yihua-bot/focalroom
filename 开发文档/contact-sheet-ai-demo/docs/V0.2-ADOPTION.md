## 核心变化

| 范围 | 已有实现 | v0.2 要求与影响 |
|---|---|---|
| 产品入口 | GUI 工作台，AI 占位 | 保留 GUI，增加上下文动作与可折叠 AgentPanel；主界面保持照片编辑 |
| 领域写入 | Repository → 多个业务 IPC → Store 方法 | 共用 DomainCommandService，命令 ID 幂等、可信执行身份、事务组、可补偿事件 |
| 人工选片 | 单张操作，重复 K/X 隐式返回待定 | K/X 明确设置状态，U 设置待定；多选批量命令，不能部分成功 |
| GUI 编辑 | 网格、检查器、比较、拖动、大图适合屏幕 | 补 Lightbox 100%/前后切换、比较缩放、命令菜单、新快捷键；按 1920×1080 和 1280×800 验收 |
| M1 | 导入、事件、备注、序列、导出 | 版本快照、恢复、整体 Undo/Redo、DB 备份/恢复、批量操作和命令幂等成为 M1 必需项 |
| M2 | 原计划 AIRun + AISuggestion/MockProvider | 替换为 AgentTask/Step/ToolCall + PolicyGate + DraftReview；Mock 必须通过实际工具写两份数据库草案 |
| 草案批准 | 尚未实现 | 模型无 ApplyDraft 权限；部分采纳保留原相对顺序、按草案顺序追加批准新增；整套采纳必须审批结果完整匹配 |
| 并发 | 正式项目 revision 冲突保护 | 新增草案独立 revision、baseProjectRevision、stale 状态；用户编辑不中断，旧草案不直接覆盖 |
| 撤销与证据 | append-only 人工事件，无整体撤销 | 补偿命令保留原审计，批准草案可一次撤销；Agent 建议不充当用户偏好证据 |
| 导出隐私 | 项目 JSON/CSV 默认包含原图绝对路径 | 默认移除私人路径；迁移导出需明确路径选项；仍只写用户选择的新目标文件 |
| 图片格式 | JPEG/PNG/WebP/TIFF 与限定 macOS HEIC/CR2 样本 | JPEG/PNG/WebP/TIFF 为 M0–M2 核心；RAW/HEIC 不再作为全格式硬门槛，已验证适配可以保留 |
| 后续路线 | M4 记忆与 Beta 合并 | M4 情境审美记忆，M5 性能、隐私、签名和摄影师试用；真实模型仍在 M3 |

**结论**：现有 Tauri/React/SQLite、离线导入、缓存、人工事件、排序、比较和导出能够复用；新版 M0 命令边界和 M1 能力尚有缺口。不能沿用旧验收结果宣称 v0.2 M1 已完成，也不能直接执行旧 M2 AIRun/AISuggestion 方案。

## 数据兼容策略

新包 `migrations/0001_init.sql` 是新库 DDL，不是现有库升级脚本。仅在内存数据库中先执行现有 `0001_local_core.sql` 再执行它，实际报错：`no such column: sequence_id`。旧 sequence_items 使用 project_id，新版使用 sequence_id；photos、备注、比较和事件字段也不同，`IF NOT EXISTS` 不会完成列升级。

后续必须新增升级 migration，保留既有 migration checksum；升级前创建一致性备份，在临时旧库验证迁移、重启及 foreign_key_check，再针对正式库执行。保留项目/照片 ID、原图指纹、备注、序列、归档状态和历史事件；将旧 `user` 来源映射为可追踪的 legacy human 证据，不删除旧事件冒充新事件。不维护两套可写正式状态。

本轮没有修改或应用应用数据库迁移，没有操作实际项目数据库，也没有改写源照片。v0.2 规划中的 Agent/记忆表仅为参考资产，尚未编入运行时。

## 调整后的实现顺序

1. **补齐 v0.2 M0 命令边界**：定义 Rust/TS Command DTO，设置统一 GUI 入口与 MockRepository；可信身份在 Rust 派生；补快捷键语义及 AgentPanel 空态与双尺寸截图。保持已有本地核心，避免目录/包管理器重建。
2. **补齐 v0.2 M1**（6 个工作项）：兼容迁移和备份恢复；统一事务命令与幂等日志；多选/批量 K/X/U；保存/恢复序列版本；事务组 Undo/Redo 与冲突；导出隐私及真实图库/性能验收。
3. **M1 验收后实现新版 M2**（6 个工作项）：Task/Step/ToolCall 状态与重启中断；Registry/PolicyGate/预算；工具幂等；Mock 工具创建两份草案；DraftReview 与确定性批准；取消/越权/过时/整体撤销测试。
4. **M2 验收后进入 M3**：真实 Provider、工具调用循环和明确预览上传授权。M4/M5 按新版规格推进。

真实 200 图验收仍需用户有权用于测试的图库；已有 200 张派生夹具能验证功能一致性，不能代表 200 张 20MB 摄影图库性能。这不妨碍先实现命令、版本和撤销缺口。
