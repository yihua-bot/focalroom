# Between Frames · Beta 试用手册

> 本文件保留 2026-10-14 的历史试用说明。当前 FocalRoom 的操作与功能边界请阅读 [详细使用操作说明书](FOCALROOM-USER-MANUAL.md) 或 [浏览器阅读版](FOCALROOM-USER-MANUAL.html)；下文有关原图、记忆、模型与共享的旧限制不代表当前实现。

版本：v1.0 M5 Review（2026-10-14）· 未签名调试构建，供试用与评审，非正式发行版。

## 一、安装与启动

1. 拿到 `Between Frames M5 Review.app`，拖入「应用程序」或直接在下载目录运行。
2. 首次打开若提示「无法验证开发者」：右键点按应用 →「打开」→ 再点「打开」（或系统设置 → 隐私与安全性 → 仍要打开）。这是因为 Beta 包未签名，正式版不会有此步骤。
3. 应用数据保存在 `~/Library/Application Support/studio.betweenframes.m5review/`；试用结束直接删 .app 即可，不会影响你的照片。

**建议**：用一份**拷贝的图库**试用（200 张左右 JPEG 最合适），虽然应用承诺只读不改原图，Beta 阶段谨慎为上。

## 二、五分钟上手感

1. **新建项目**：起个名字，写一句创作意图（例如「克制的家庭日常，要有时间感」——这会直接影响 AI 建议）。
2. **导入**：点「导入照片」选文件夹，等缩略图生成完（200 张约几秒到几十秒）。
3. **选片**：点照片，按 `K` 保留、`X` 淘汰、`0–5` 打星；写几句「为什么留它」的备注——**你的备注是 AI 理解你审美的最重要素材**。按 `?` 查看全部快捷键。
4. **比较**：选中两张按 `C`，二选一或「不确定」都行。
5. **序列**：底部「已保留」条进入序列，拖动排序。

到这里，**不碰任何 AI 功能也能完成全部工作**——这是产品底线。

## 三、试用 AI（本地 Mock，零上传）

1. 右栏「Agent · 本地 Mock」→ 填目标（如「给两版 25 张序列」）→ 开始任务。
2. 观察：任务步骤实时可见、可暂停/取消；预算（轮次/工具数/时长）可在面板里改。
3. 完成后出两份草案 →「查看草案差异」→ 勾选部分照片 →「采纳所选」或全量替换（都可撤销）。
4. **审美记忆**：右侧「审美记忆」面板会从你的备注中归纳偏好假设；每条可点开看证据、可纠正（纠正后 AI 不再引用）。

## 四、接真实视觉模型（可选）

1. 准备一个 OpenAI API Key。
2. Agent 面板 →「模型与密钥 · 诊断」→ 粘贴 key →「存入钥匙串」（存系统钥匙串，不进数据库/日志）→ **重启应用**。
3. 再开视觉任务时会弹出**图像授权卡**：显示上传几张、什么尺寸、预估费用；三档选择——仅本次任务 / 本项目（可撤回）/ 禁止云端。拒绝后视觉功能降级为元数据对照，其余一切照常。
4. 面板实时显示图像用量与估算费用（保守估算，非账单）。

## 五、试用中请重点反馈

- AI 建议是否「引用了真实存在的照片」、理由是否贴合你的意图；
- 草案 diff 和局部采纳是否符合直觉、撤销是否可预期；
- 记忆假设像不像你（证据链是否说服你）；纠正后是否真的不再犯；
- 授权卡的信息是否足够让你放心；预算/费用显示是否清楚；
- 200–500 张图库下的导入速度、滚动流畅度、快捷键手感。

**反馈模板**（发给项目组即可）：项目规模（多少张）／做了什么／期望什么／实际什么／截图或诊断信息（Agent 面板 →「模型与密钥 · 诊断」→「查看本地存储与诊断」→ 检查后「复制诊断信息」，不含隐私内容）。

## 六、已知边界（Beta 如实声明）

- 未签名/公证；真实模型路径的端到端行为仍在验证（Mock 路径已全自动化覆盖）；
- 100% 放大查看的是最长边 1400px 预览，非原图逐像素；
- 偏好假设来自你备注中的关键词归纳，不做语义理解；跨项目记忆未开放；
- 偏好证据暂不提供单条删除（假设可纠正/停用）；
- 更多细节见应用内「隐私与数据说明」（docs/PRIVACY.md）。

## 七、出问题时

- 任务卡住：暂停 → 取消 → 重新委托（已完成的草案和你的正式编辑不受影响）。
- 数据异常：应用数据目录下 `projects.sqlite` 可直接备份；删除该目录 = 清空试用数据（原图无损）。
- 崩溃/报错：复制诊断信息 + 截图反馈；不要发 API key 给任何人（包括我们）。

## 本地存储与诊断

在 Agent 面板展开「模型与密钥 · 诊断」，点击「查看本地存储与诊断」。可查看数据库、WAL、共享内存、图片缓存与迁移备份的大小，以及全库项目/照片/任务计数；「刷新统计」更新快照。复制前可展开 JSON 检查内容，只有点击「复制诊断信息」才写入剪贴板。

「至少」或「暂不可用」表示部分条目未能统计，不能按 0 使用。文件大小合计不含原图、导出文件或应用本身，也不证明备份能够恢复。此处没有清理或发送操作。
