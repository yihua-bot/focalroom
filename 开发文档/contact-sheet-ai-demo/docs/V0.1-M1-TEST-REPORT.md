## 夹具与格式复现

- Rust 200 张图库：测试生成 128×96 JPEG，每张指纹不同，用于事务与重启一致性，不代表高分辨率性能。
- 浏览器 200 张图库：由仓库 28 张示例图生成最长边 480px JPEG，添加唯一 COM 段保证文件指纹不同；只用于功能验收，不当作摄影师真实项目。
- HEIC：系统 `sips` 从仓库示例图输出到 `/tmp`，随后 Rust 导入并验证源文件 SHA256 不变。
- RAW：来自 [rawpy 测试样本](https://github.com/letmaik/rawpy/tree/master/test)，Canon 40D sRAW CR2 V1.0.3，1936×1288；未加入仓库或正式分发包，不推定素材商用授权。

```bash
sips -s format heic "../assets/frame_01.jpg" --out "/tmp/between-frames-heic-fixture.heic"
curl -L --fail "https://raw.githubusercontent.com/letmaik/rawpy/master/test/RAW_CANON_40D_SRAW_V103.CR2" \
  -o "/tmp/between-frames-raw-fixture.CR2"
```

本次 RAW 源 SHA256：`152382ce4dbf644899d12b41b4c577f07638aa3ec5745ac344c36bad93826125`。HEIC 源 SHA256：`6e648c6321ff8e75624c0ecca08a5b88d1bedefe8c66e536af5f67d68edd1946`。HEIC 重生成可能不同，但每次导入前/后的指纹必须相同。

若上述夹具不存在，原生格式测试会明确输出 SKIP；本次两者均实际运行并通过。其他 RAW 格式仅提供平台尝试入口，不能宣称已验证。

## 修正记录与架构

测试揭示图像 `thumbnail()` 会放大小图，首轮 200 张测试耗时约 130s。修正为只缩小后，后端全套约 3.27s。该数字仅属于小夹具，不外推到 200 张 20MB 图库。

macOS `/var` 与 `/private/var` 路径别名导致原图保护和测试夹具 scope 比较不一致，已规范化路径。JPEG 会量化单像素变化，测试夹具使用唯一 COM 段确保去重验证稳定。Playwright 两套测试使用不同输出目录，避免覆盖 trace。截图检查进一步确认比较使用 1400px 编辑预览。

业务服务按 Store、图像流水线、导入任务和导出职责拆分（SRP）；UI 依赖 Repository 接口（DIP），不执行 SQL；事件和投影共享事务（DRY），只实现 M1 需要的本地能力（KISS/YAGNI）。详见 [DECISIONS.md](../DECISIONS.md)、[M1-FILES.md](M1-FILES.md)。

## 桌面构建及原生补验

本机沿用命令级镜像下载依赖，没有修改全局 Cargo 源。最终 Debug 构建：

```bash
npm run tauri build -- --debug -- \
  --config 'source.crates-io.replace-with="m0-mirror"' \
  --config 'source.m0-mirror.registry="sparse+https://rsproxy.cn/index/"' --offline
```

产物：`between-frames/src-tauri/target/debug/bundle/macos/Between Frames.app`，约 41.81 MiB，arm64。前端构建有单包超过 500kB 的提示，非构建失败。

已实际启动进程，并创建 `~/Library/Application Support/studio.betweenframes.desktop/BetweenFrames/projects.sqlite`。首轮屏幕检查曾因 Mac 锁定受阻；用户回复继续后，原生窗口已可访问，锁屏阻塞解除。

原生补验：系统文件夹选择器导入 200 张示例派生 JPEG，新增 200、失败 0；K/X/方向键与备注输入隔离、保存备注、比较不改写人工状态、序列按钮与键盘把手排序通过。系统保存对话框导出 JSON/CSV/HTML，三个文件 SHA256 与回执一致。Cmd+Q 后确认原生进程退出，再启动并打开项目，20 keep、1 reject、179 undecided、备注、序列和事件均恢复，6 张表快照完全一致；200 个源 SHA256 不变。

首轮鼠标拖动未产生顺序变化，记录见 [NATIVE-M1-TEST-REPORT.md](NATIVE-M1-TEST-REPORT.md)。后续移除把手启动距离阈值，最终原生构建鼠标排序通过；重启后六表快照再次完全一致，200 个源 SHA256 不变。修正与重新执行的自动化结果见 [M1-DRAG-TEST-REPORT.md](M1-DRAG-TEST-REPORT.md)。
