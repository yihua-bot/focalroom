# v1.2 实施计划（第一轮）

依据主规格 §17：摄影书序列与页跨图编辑、导出印刷参考 PDF、独立图像元数据侧车文件。本轮交付导出类两项；页跨图编辑涉及序列模型扩展，待前两项试用反馈后设计。

1. 印刷参考导出（format=print）：A4 横版分页 HTML——封面（标题/意图/统计/导出时间/使用说明）+ 每页两图（1400px 预览、序号、虚线裁切参考）；浏览器「打印→存为 PDF」即得 PDF，不引入 PDF 生成依赖。明示非色彩管理。
2. 元数据侧车（format=sidecar）：每张照片一个 JSON（状态/评分/备注/序列位/指纹/缺失标记）+ manifest.json；目录级导出、只新建不覆盖、路径默认私密可 opt-in。
3. 测试：export_v12 两项（版式结构断言 / 侧车内容与安全语义）；全量回归 verify-all。

KISS：PDF 走系统打印通道（HTML 即版式载体）；侧车为纯 JSON 无二进制。ADR 0010 记录决定。
