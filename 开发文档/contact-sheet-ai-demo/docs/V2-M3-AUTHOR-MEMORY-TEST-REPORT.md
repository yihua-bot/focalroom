# M3 本地作者记忆检索验收

日期：2026-10-17（Asia/Shanghai）。接续持久化语义索引切片；设计见 [ADR 0037](ADR/0037-m3-local-author-memory.md)。M3 整体仍 partial。

## 已实现的功能

- Memory Studio 新增明确授权开关，默认关闭。开启需确认，关闭直接生效；更改通过既有 MemoryRequest/CommandHandler 的严格契约、SQLite 写事务和持久化回执。相同请求重放不重复执行，相同状态不更新时间；旧直接写入的 true 不算有效授权。
- 开启后，离线 Agent 上下文和 retrieve_preferences / retrieve_memory 的 global_confirmed 路径可引用其他活跃 LOCAL 项目的相关、已确认、有有效证据的假设。云模型、共享/迁移中/归档项目、未确认或停用线索排除。当前项目的可编辑假设与证据保持独立，其他项目用只读卡片和来源链接展示。
- 输出附 memory_id、source_project_id、支持/反例 evidence_refs，不返回来源原始备注、照片 ID、文件名、路径或像素。作者线索只是带来源的引用，不自动建立永久风格或照片操作权限；同词去重，已有纠正/停用/退役/墓碑防止同词从另一来源复活。
- 任务首次委托绑定不可变的授权 epoch、提供方及来源版本摘要，检查点只复制原绑定。撤权、来源记忆/人工证据或项目可用范围变化后，旧任务不能继续请求模型、提交结果或回放工具；须重新委托。来源证据在模型等待期间变化时，保留已报告用量，丢弃回复。已有草案和审计历史保留。
- 来源最多 100 个项目；超限明确拒绝，界面仍能关闭授权。上下文最多 3 条，工具/只读列表最多 10 条。没有新迁移、依赖、服务或模型请求；复用现有命令/回执/检查点，授权与内容检索分别负责。

## 验证结果

最终各项检查通过：**174 项桌面 Rust、13 项本地云测试、173 项 Vitest、16 项预览 E2E、6 项真实后端 E2E**；契约、类型、Lint、fmt、严格 Clippy 通过。桌面默认 13 项 ignored，钥匙串写删 1 项 filtered，均未计作通过。新增作者记忆测试 10/10 全部通过。

首轮 verify-all exit=1（5/6 后端旅程通过）；修正仅涉及 E2E 异步断言及测试读取当前来源快照，生产代码不变。随后 Lint exit=0、整个真实后端套件 exit=0、6/6 通过（1.3 分钟），没有把首轮失败抹去。此前通过的 Rust/前端/契约检查对应相同生产代码。

独立原生 debug 应用在全部界面测试结束后顺序构建成功（58.57MiB，studio.betweenframes.m1reviewfixes），NaturalLanguage 弱链接检查通过；未启动原生窗口或打开用户库。243 个归档源码/契约/测试文件摘要复核一致。90 张本轮开始时已有截图全部字节一致，恢复了 25 张测试产物；没有用 HEAD 覆盖起始工作区。新作者记忆界面截图已检查，来源卡只读且可与本项目可编辑卡区分。完整日志、原始失败 trace、摘要、构建元数据见 evidence/v2-m3-author-memory/。

本轮新增 10 项作者记忆 Rust 集成测试、4 项前端单测；改写旧跨项目测试，使用真实人工证据和正式授权通道，移除未经审计直接设置的测试入口及原 1 项设置单测。

| 场景 | 验收内容 |
|---|---|
| 授权与幂等 | 默认隔离、旧 true 不算同意、有效审计、同值 no-op、回执重放/参数冲突、未知 user 不读取授权 |
| 原子性 | 回执插入故障回滚授权和任务暂停；项目正式状态不变 |
| 来源过滤 | 仅已确认且相关、证据有效；排除未确认、归档、PROMOTING、SHARED_CACHE；目标非 LOCAL 同样排除 |
| 溯源与权限 | source_project_id / memory_id / evidence_refs；上下文无来源照片标识/文件名；云路径拒绝、项目内工具不混入作者线索、外项目工具参数拒绝 |
| 用户否决 | 纠正、停用、退役、假设墓碑阻断重复关键词；支持证据全部排除后来源不再参与 |
| 恢复与回放 | 跨项目撤权再开启的 ABA 仍拒绝旧任务；来源控制暂停消费者；归档后运行转 paused；旧工具结果拒绝重放 |
| 模型等待 | 来源普通人工备注变更后，晚到回复不落入 model/tool step；注入的 13/7 token 正确结算，仅离线测试计量 |
| 检查点与资源 | 不可变 step 不能改写；检查点缺失绑定拒绝，恢复不刷新来源摘要；超过 100 来源拒绝且可关闭 |
| GUI 与真实后端 | 开启确认/取消、只读来源链接、进程重启保留、关闭隐藏；当前/来源正式投影及测试原图 hash 保持不变；拦截并断言零外部页面请求 |

首次全量脚本在新增界面测试失败：Playwright checkbox.check 要求点击完成时立即勾选，而该控件在后端持久化后才更新受控值。trace 显示控件正处于禁用的保存状态。测试改为一次 click 后等待持久化的 checked 状态；关闭同样等待，未改产品逻辑、加重试或延长超时。首轮日志和 trace 保留于 evidence/v2-m3-author-memory/，不能把首次 exit=1 改写为通过。

## 复现

在 between-frames 目录依次执行：

    bash "scripts/verify-all.sh" --skip-keychain
    BETWEEN_FRAMES_OPENAI_API_KEY="" CARGO_TARGET_DIR="target-v1" npm run test:integration

独立原生 debug 打包必须在使用 Vite 的所有 E2E 结束后运行，避免构建产物触发开发页面刷新。所有测试使用临时库和测试素材，实际模型 Provider 显式禁用。Prompt m3-openai-8 / m2-mock-2，视觉和向量缓存版本保持不变；本轮没有新真实 Provider 回归。默认 ignored 测试与钥匙串写删没有算作通过；此前切片的真实语义模型和 LUMIX 记录不重复计入本轮。

## 剩余问题

- 本轮只完成单一本地作者的离线跨项目引用；云模型的作者记忆传输授权、真正 Creator/Workspace 多身份隔离和组织禁用策略仍需后续实施，不代表 M02 全部通过。
- 默认 Mock 仍是元数据策略，接线不代表获得离线审美推理能力。作者偏好依然由二元关键词/FTS5 规则生成和检索，不是语义风格模型。当前项目线索优先，可能挤占 3 条上下文；跨项目召回率、专业审美质量与大量来源性能尚未测量。无关来源变更、新建项目也可能保守触发重新委托。
- 撤权不能清除已读历史、已有工具回执、备份或内存；摘要信任既有命令通道，不防同机恶意直接改库。设置没有自动升级为多账号隔离。
- M3 仍缺低价观察/高能力策展的受控分工、完整 Adapter/供应商专属授权与 fallback 执行、预算/账单校准、至少 30 项任务/专家与竞品同题评价及真实摄影师闭环。模拟角色不能替代真人质量证明。
- M4/M5 生产身份、Postgres 权威、云审批正式事务、实时同步等继续单列；本轮未操作用户库或线上环境，也未提交/推送。完整清单见 [剩余计划](V2-REMAINING-PLAN.md)。
