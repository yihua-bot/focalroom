# M1 本地工作流验收

启动桌面 `Between Frames.app` 或 `npm run tauri dev`。浏览器 `npm run dev` 仍只提供示例预览。

1. 项目列表新建项目，写名称和创作意图；关闭/重开后应仍在列表。
2. 导入照片或文件夹，确认进度、新增/重复/失败数量；取消后只保留已完成部分。失败项可重试。
3. K/X 与方向键选片，检查三状态数量和入选底带；照片按完整构图显示。
4. 写备注，切换照片再返回应保留草稿；保存后重启应保留内容。
5. 两图比较选择左、右或不确定，不应修改人工状态。Tab 留在对话框，Esc 关闭。
6. 作品序列拖动把手、上下移动；重启后顺序不变。旧窗口的 revision 冲突应明确提示并刷新。
7. JSON/CSV/接触印相导出到新文件名，查看内容与 SHA256；已有文件不可覆盖。
8. 对测试照片模拟原图移动，仍应显示缓存和失联标记；重新定位必须匹配原指纹。
9. 归档项目后可在归档列表恢复；原图、状态、备注和日志应保留。
10. AI 面板仍为明确占位，整个本地流程无需网络。

原生系统对话框/WKWebView 和摄影师真实图库验收尚待补充，见测试报告。不要移动真实原图来测试失联，使用测试副本。
