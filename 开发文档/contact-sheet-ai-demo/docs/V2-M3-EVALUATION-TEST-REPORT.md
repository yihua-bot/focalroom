## 修复与设计

1. PolicyGate 在原任务与服务档位上限内缩小本轮输出，不扩大总预算。实际请求上限、预留额、费率版本写入现有 `model_attempt` JSON；结算从账本读取，不按原 8192 重算。超过发送上限在新工具执行前暂停。未知分项 usage 保留预留。
2. 已确认的 `https://api.deepseek.com + deepseek-flash` 使用 `deepseek_flash_peak20261016`；按峰时非缓存输入 $0.30/M、输出 $1.20/M 估算，整数计算并逐请求向上取整为美分，缓存/非峰时不打折。视觉仅有总 token 时按更高输出单价估算，仍非账单。未知模型/端点继续旧保守规则；不以模型输出选择费率。费率版本在模型/视觉账本中保存，旧记录不重写。来源为 [DeepSeek 官方价格](https://api-docs.deepseek.com/quick_start/pricing/)；[Responses/视觉协议](https://api-docs.deepseek.com/guides/responses_api/) 于本轮核对。
3. 视觉预留事务补齐服务档位有效费用上限。Standard 仍为 50 美分、任务配置仍为 100 美分，本轮没有提高任何既有任务或档位上限；估算口径变化不能当作实际账单下降的对比实验。
4. 草案目标按审阅页的 `keep` 候选计算；附带待定/淘汰项仍检查唯一 ID、连续位置及真实项目。候选不足/过多、暂停、零草案、超预算仍拒绝。
5. 分页错误提供可信任务 ID 的合法 JSON 示例，继续拒绝字符串 `"null"` 和无效游标。视觉 Prompt 明确单一 JSON 对象、数组和无代码围栏；严格解析不放宽。失败只记录类别/行列/字节数/围栏标志，不记录供应商原文；未确认第一次失败的具体语法根因，不能声称所有格式问题已根除。
6. 新增 `tools/agent-eval`：严格 schema、任务/来源/授权/反馈分层、预登记 attempt、失败分母、账单/估算区分、hash 审计、匿名候选、冻结摘要、作者+独立评审、五维分项、事实抽查与后续采纳记录。CLI 只写新目录；离线 HTML 使用本地图片，支持内嵌预览和键盘放大，文本通过 textContent 呈现。

代码沿用 PolicyGate、CommandHandler 和现有账本；费率计算集中于 `agent/pricing.rs`，评测规则/文件写入/预览封装分离。不增加服务骨架、依赖或 schema 来承载这些本地功能。决策与回退见 [ADR 0030](ADR/0030-m3-adaptive-output-and-evaluation.md)。
