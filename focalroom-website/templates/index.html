PROJECT / EXPLORE / RETURN

一个项目，可以反复回来。

作品往往在重新选片、调色和讨论中成形。FocalRoom 围绕这个循环设计，让不同方案有各自的位置。

  1. 01

    研究与构思

    记录主题、参考影像和想表达的内容。Research & Moodboard 正在规划中。

  2. 02

    图库与选片

    导入照片、比较与保留。技术质量和照片在作品中的作用，可以分别判断。

  3. 03

    叙事与编排

    在现有作品序列中寻找节奏；自由画布的并置、分组与标注正在完善。

  4. 04

    调色与共同编辑

    通过 Web 邀请编辑评片；Lightroom Classic / Capture One 的版本往返仍在开发。

  5. 05

    作品呈现

    摄影书、展览与印前交付是产品方向，尚未作为完整制作能力发布。

A FEW THINGS TO KNOW

开始之前，
你可能想问。

打开详细操作说明 ↗
Research、画布和摄影书现在都能用吗？+

尚未完整发布。研究参考板属于规划；画布、外部调色往返、共享画布与摄影书正在开发和验证。现有下载版与官网演示不代表完整创作闭环已经交付。

谁适合使用 FocalRoom？+

希望整理长期项目、编辑组照或与编辑共同评片的摄影创作者。艺术摄影师、摄影书作者、摄影编辑和工作室可以从现有选片与序列功能开始；完整出版制作仍在开发。

FocalRoom 能替代 Lightroom 或 Capture One 吗？+

不能。FocalRoom 专注选片、视觉编辑、叙事与评审。继续用熟悉的软件显影、调色和精修；两者之间的自动版本往返仍在开发。

不用 AI，也可以使用吗？+

可以。桌面的导入、保留与淘汰、评分、比较、序列、版本和导出可以独立使用。

一句创作目标，就能自动选片吗？+

先导入照片，再告诉 AI 创作目标。真实分析依赖可用服务、账户额度与本次任务范围；草案经你采纳才改变正式选片。官网演示使用预设建议。

共享之后，桌面还能继续修改吗？+

有两种方式：导出共享预览包会建立独立副本，本地项目仍可编辑；正式迁移为共享项目后，桌面保留迁移时的只读快照，后续评片在 Web 进行。两种方式均不上传原图文件。

支持哪些设备？在哪里获取应用？+

支持 macOS 11 及以上的 Apple Silicon Mac。现有下载版为 1.0.4；Intel Mac 和其他桌面平台尚未完成发行验收。Web 评片可通过浏览器访问，完整 v3 规划不包含在现有安装包中。

官网演示会上传我的照片吗？+

不会。这里使用的是已经随页面提供的 AI 生成样片，不提供个人照片上传入口。示例建议由本页预设规则生成，保留与排序仅存在当前页面，刷新后重置。
