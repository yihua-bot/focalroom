FocalRoom / Editor bridges

插件与安装说明

在熟悉的软件调色，把照片带回 FocalRoom。

macOS 11+ · Apple Silicon / Intel · 版本 1.0.0

支持范围

Lightroom Classic 提供导出插件；Capture One 使用独立桥接应用。结果保存在本机，不上传照片，也不改动原片。

当前不包含双向目录同步、自动回写评分或印刷色彩保证。尚未完成实际 Lightroom / Capture One 环境验证，请先用少量照片副本确认结果。

Lightroom Classic

下载 Lightroom 插件

安装与导出

  1. 解压下载包，保留完整的 FocalRoom.lrplugin 文件夹。
  2. 打开 Lightroom Classic → 文件 → 增效工具管理器 → 添加，选择该文件夹并启用。
  3. 选中照片 → 文件 → 导出，在“导出到”选择 FocalRoom。选择 JPEG 或 TIFF，完成导出后按提示选择保存位置。

仅支持 Lightroom Classic，不适用于云端版 Lightroom 或移动版。插件会读取原片确认对应关系，请确保原片在线。

Capture One

下载 Capture One 桥接应用

安装与导出

  1. 解压下载包，把 FocalRoom Capture One Bridge.app 拖入“应用程序”，打开一次。
  2. 在 Capture One 导出调色后的 JPEG、PNG 或单页 TIFF，等待导出完成。
  3. 在桥接应用点击“添加导出的照片”，逐行选择对应原照片，然后点击“保存并带回 FocalRoom”。

也可在访达中选择已经导出的照片，通过“打开方式”交给桥接应用。它不是 Capture One 原生插件，不应放入 Plugins 文件夹。

Capture One 的原图“Open With”不会包含调色。请先导出，或使用“Edit With”生成 JPEG / TIFF 后交给桥接应用。

该桥接需要手动确认原片，不读取 Catalog / Session / Variant，也不会自动同步这些内容。

带回 FocalRoom

有“调色版本”入口的客户端

先在当前项目导入对应原片，再打开选片工作台 → 调色版本 → 导入调色结果，选择插件生成的 FocalRoom 文件夹。结果单独保存，可点击放大；原片、选片与序列不变。

没有该入口的已安装版本

使用“导入照片 → 选择文件夹”导入结果。这会新增独立照片，不会与原片合并。调色版本入口需要包含此功能的新版客户端；本页插件不会自动升级客户端。

每批最多 500 张，单张导出结果不超过 512 MB。支持 JPEG、PNG 和单页 TIFF。16 位文件保留原始字节，当前查看使用缩小预览，不作为印刷软打样。

遇到问题

找不到对应照片：先检查项目，再确认选择的是最初导入的原文件。请勿按同名文件强行合并。

系统阻止打开：请记录提示并联系作者，不要关闭系统安全保护。

卸载：Lightroom 在增效工具管理器中移除插件；Capture One 桥接应用退出后从“应用程序”移除。已保存照片不受影响。
