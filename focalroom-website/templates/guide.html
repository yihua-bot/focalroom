FOCALROOM / GETTING STARTED

快速使用指南

官网展示与当前版本

研究参考板、叙事画布、调色往返和出版制作的状态，请查看产品方向页；这里的快速指南不把规划中的功能当作已发布步骤。

产品方向 ↗

先完成一次人工编辑，再按需加入 Agent 和协作。以下介绍当前已实现的流程，界面名称以应用实际显示为准。

本指南支持中、英、日、韩。桌面应用与共享工作区的界面语言独立于官网；切换官网语言不会更改应用界面。

项目与导入选片与序列委托 Agent审阅草案图像授权审美记忆共享评片数据与导出

1. 创建项目，导入素材

在桌面点击「新建项目」，填写名称与创作意图，再选择照片或文件夹导入。原图保留在原目录，应用建立引用与预览缓存。

相机卡和外置硬盘需要保持可访问。想在拔卡后继续检视原图，应先把素材复制到固定目录，再导入。缓存不能替代原片备份。

2. 选片，编排并保存版本

用 K 保留、X 淘汰、U 恢复待定；1–5 打星，0 清除评分。备注输入后须明确保存。星级与保留状态相互独立，淘汰不删除原图。

进入「作品序列」拖动排序，或使用上移、下移。保存命名版本以保留选片、顺序、评分与已保存备注；正式编辑可通过撤销或版本恢复调整。

原图、RAW 内嵌 JPEG 与派生预览不同。检视细节时先看来源提示；当前不是完整 RAW 显影或专业印刷色彩工作站。

3. 给 Agent 一个明确目标

进入选片工作台，点击「AI 智能选片」，在对话中说明创作目标。张数和处理范围按任务选择，开始前核对本次将分析的照片。

从这些照片中选出 12 张安静的海岸作品。减少相似画面，给出顺序和理由；以空间开场，以人的痕迹收尾。

AI 功能依赖账户额度和当前可用服务。任务可能只观察部分照片；请根据实际覆盖和草案理由判断，不要把建议视为最终结论。

4. 先审阅，再采纳

查看草案差异，逐项核对照片、理由、加入、移出和位置变化。可以只采纳部分，也可以确认全量替换，或丢弃草案。生成草案本身不会改变正式选片。

草案基线过期时先重新比较，必要时重新委托。预算暂停可按明确调整后的限额恢复；模型、授权或记忆变化可能要求新建任务。

5. 分开决定文字、图像与共享授权

真实文字任务也可能向配置的服务发送目标、文件名和备注。视觉任务上传最长边 1,400px 的重编码 JPEG 预览，需核对实际观察服务与型号，再选择仅本次、本项目或禁止图像上传。

撤回授权阻止后续发送，无法收回已经发出的内容；清空本机观察缓存不等于删除服务商的记录。

6. 查看证据，纠正记忆

在「审美记忆」查看人工证据、偏好假设与反例。你可以确认、纠正、停用或移除假设，也可以排除证据参与学习。删除当前记录不可当作清除了所有历史和备份。

跨项目记忆默认关闭，当前只供离线 Agent 引用符合条件的其他本地项目线索。共享项目和云模型不参与；记忆变化后请按提示重新委托。

7. 选择合适的共享方式

共享预览包在 Web 建立独立副本，本地原项目继续独立编辑；正式迁移为共享项目则冻结桌面写入，完成后在 Web 继续，桌面仅显示迁移时的初始快照。

迁移超时不代表没有上传。使用原服务与账户恢复，或验证云端未提交后取消；已经提交的迁移不能直接取消。共享不上传原图，也不自动授权 AI。

在 Web 用指定邮箱接受项目邀请。Reviewer 可批注和提案，Viewer 只读，Editor 的审批须独立授权。作者或有审批权的成员逐项批准，正式作品才改变。

网络断开时正式作品只读；重连后核对最新版本再提交。未保存的编辑可能因关页丢失。撤销权限无法收回对方已经下载或截图的像素。

8. 导出与保管数据

在桌面导出项目 JSON、选片 CSV、接触印相、印刷参考、元数据侧车或共享预览包。使用新文件名并打开结果核对；默认省略本机路径，但自填文字可能仍含隐私。

印刷参考导出为 HTML，可在浏览器打印为 PDF。完整本地备份需退出应用后复制对应数据目录，并独立保管原图；共享服务还需管理员备份数据库与预览对象。
