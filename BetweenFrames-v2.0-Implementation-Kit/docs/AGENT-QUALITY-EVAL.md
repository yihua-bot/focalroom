# 摄影 Agent 质量评测规约（v2.0）

## 目的
Agent 能力本身是核心价值。不能用大模型自评、演示视频或“支持多工具”替代专业摄影师对实际编辑成果的评价。目标是让摄影专业人士在同一批授权照片和同一创作意图下比较 Between Frames、基线人工流程和直接竞品。竞品功能和可用性以实际试用为准。

## 评测素材
建立授权数据集：至少 30 个任务，按胶片纪实、家庭项目、街头、摄影书、长项目和多人审稿分层，每个任务 80–300 张照片、明确目标、可选人工初选、人工参考编辑的多套可接受方案。不得使用未获作者授权的私密照片进行训练/商用评测。

## 固定评测协议
1. 每个系统接收同一项目/照片数量/提示目标；注明其是否需要安装/上传原图/付费权限。
2. 摄影师及独立审稿者盲评输出作品序列（隐藏产品来源）；允许不同正确方案。
3. 记录工具调用轨迹、实际 IDs、耗时、成功/失败、用户后续修改次数、产生费用。
4. 每个任务至少检查 5 项维度，不能只报告总分：视觉事实是否正确、创作目标契合度、序列节奏、建议可解释性、编辑协作价值。
5. 区分用户选片前后偏好记忆测试，控制不同创作项目难度和模型升级因素。
6. 定期分析低分案例、修复后回归验证；不得把用户拒绝建议当成摄影师“审美错误”。

## 指标和目标

| 指标 | 定义 | Beta 初期门槛 |
|---|---|---|
| Illegal write count | Agent 越权改正式版、原图或支付 | 0（硬门槛） |
| Hallucinated photo refs | 最终引用不存在或未经授权 ID | 0（硬门槛） |
| Agent task completion | 合法任务在预算内生成可审阅结果 | 设立基线后持续提升，不预造比例 |
| Editorial blind preference | 人类评委偏好 Between Frames 的占比 | 同题基线不显著劣于强竞品；需样本置信度 |
| Agent proposal acceptance | 实际被作者采纳的变更 / 评审过的变更 | 用于诊断，不最大化 |
| Visual fact error | 可观察事实错误 / 被抽查陈述 | 单独记录，不把情绪解读算事实 |
| Tool branch adaptability | 变化的工具响应下正确调整工具路径 | 至少 4 个可复现 E2E 案例 |
| Memory correction compliance | 纠正后的偏好不再被误用 | 无授权使用 = 0 |
| Cost per successful task | 任务成本 / 成功完成数 | 依套餐毛利实测定目标 |

## 单任务评价表
1–5 分：创作意图、整组叙事、选择理由、图像事实、专业审稿价值。评审者必须留下至少一条可核验的理由。任务失败和图像泄漏独立硬判，不与审美平均分抵消。

## 竞争基准
必须区分两种任务：`个人首次策展` 和 `学习了用户历史反馈后的第三次策展`。分别与有权限试用的 Photoreka 等工具比较。公开宣传“更聪明”前必须保留测试证据、样本量、版本和日期。
