# FocalRoom 宣传物料

主题：**从照片，到你的作品。**

这套物料面向摄影师、独立创作者与共同审稿的编辑。深色摄影工作室配色，蓝色品牌点缀，海边摄影叙事。以真实产品组件配合原创摄影氛围素材呈现，不宣传尚未完成的专业色彩、修图往返、印厂交付或收费能力。

## 素材与真实性

- Logo：沿用项目现有已抠图的 FocalRoom 标记，没有重新生成或改变标记图形。
- 摄影背景与 12 格摄影图集：使用内置 imagegen 工具原创生成，未使用 LUMIX 或其他私人照片。完整提示词见 source/IMAGE-PROMPTS.md。
- 产品界面：从当前 FocalRoom 实际 React 组件渲染和截取，包含选片工作台、AI 抽屉、作品序列、Web 审稿。
- 项目「沿海，慢下来」、账户、选片状态和审稿评论为隔离的宣传示例，未连接生产 API，未触发真实 AI 推理或付款，也不作为摄影师背书、实际客户评论或真人评测结果。
- 影像图集通过 SVG 视口用于画面布局；原始生成 PNG 保存在 assets/。产品截图保留比例，未使用生成模型伪造产品界面。
- 片中不承诺选片准确率、节省时间比例、订阅价格或尚未确认的上线日期。

## 后续修改

source/studio.js 保存文案、配色、场景时长、动态排版和海报布局。
source/music.py 是原创配乐工程。source/render.mjs 可重导出当前画面与视频。
assets/ 保存原始摄影素材、Logo、界面截图和配乐；qa/ 保存分镜、关键帧和验证记录。

在当前 Mac 和项目依赖环境中重新导出：

    node "source/render.mjs" --final

重新生成音乐：

    python3 "source/music.py"

重新截取最新产品组件：

    node "source/capture.mjs"

移动工程到其他电脑时，需在工程目录安装 package.json 中的本地依赖与 Playwright Chromium，并准备 FFmpeg；重新合成配乐另外需要 Python 和 NumPy。中文排版在本机使用系统宋体与苹方，其他系统应替换为可用中文字体后重新验版。重新截取界面还需要 FocalRoom 产品源码；使用已附截图修改视频/海报不需要运行产品。

以上脚本只面向本地宣传素材目录。实际产品源码未因本次宣传制作而修改，没有自动提交或发布官网。
